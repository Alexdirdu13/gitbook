# Comment justifier une transaction dont le justificatif est perdu ?

## Transaction sans justificatif

Cliquez sur le bouton "**Trésorerie**" dans le menu principal à gauche de la page.

Ensuite, cliquez sur "**Transactions**" puis sur le bouton représenté par la "**Lettre A**".

Enfin, dans la liste qui s'affiche, selectionnez "**Justificatif perdu**".

## Statut de transaction

Quand vous aurez indiqué que le justificatif de la transaction est perdu, le statut de celle-ci va se mettre à jour en violet "**Justificatif perdu**".
