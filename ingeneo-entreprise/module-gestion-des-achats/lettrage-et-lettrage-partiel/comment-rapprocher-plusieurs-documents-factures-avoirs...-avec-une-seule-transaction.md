# Comment rapprocher plusieurs documents (factures, avoirs...) avec une seule transaction ?

## Accéder au lettrage

Dans certains cas, on peut vouloir **rapprocher plusieurs documents avec une seule transaction**. Par exemple :

* une facture fournisseur et un avoir fournisseur avec un décaissement (net de l'avoir) ;
* deux factures fournisseurs avec un décaissement (dans le cas où je règle deux factures en un seul virement).

Dans notre exemple, nous allons rapprocher une facture fournisseur et un avoir avec le décaissement net.

On commence par rechercher un des documents que l'on souhaite lettrer, puis on clique sur l'icône **A** sur la ligne du document pour faire apparaitre la fenêtre de lettrage.

## Rapprocher l'avoir et le décaissement

On recherche ensuite le(s) autre(s) document(s) à lettrer (dans la partie **Achats** ou **Ventes**) : ici notre avoir fournisseur. On clique dessus pour qu'il apparaisse dans **Opérations associés** (2).

On recherche ensuite la transaction bancaire (ici le décaissement net de l'avoir).

Puis cliquez sur **Confirmer**.

**Attention :**

N'oubliez pas de retirer les filtres automatiques de recherche comme "Égale à..." dans la colonne **Montant**.

## Voir le lettrage complet

Cliquez ensuite dans les factures ayant le statut "Justifié". Vous y retrouverez la facture affichant "lettrage complet".
