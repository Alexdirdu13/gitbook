# Comment lettrer une transaction ?

## Chercher la transaction

Cliquez sur le bouton "**Trésorerie**" dans le menu principal à gauche de la page.

Ensuite, cliquez sur "**Transactions**" puis sur le bouton "**A**" à droite.

Enfin, cliquez sur "**Lettrage**" dans la liste qui s'affiche.

**À savoir :**

Attention : il faut avoir le module "Trésorerie" pour pouvoir y accéder.

## Lettrer la transaction

Une nouvelle fenêtre **Lettrage du document** s'ouvrira, sélectionnez votre transaction.

Celle-ci apparaîtra dans la section **Opérations associées**.

L'outil calculera automatiquement le restant à rapprocher.

Puis confirmez.
