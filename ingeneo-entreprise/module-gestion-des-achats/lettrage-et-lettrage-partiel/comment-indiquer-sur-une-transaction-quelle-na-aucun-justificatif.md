# Comment indiquer sur une transaction qu'elle n'a aucun justificatif ?

## Indiquer sur une transaction qu'elle n'a pas de justificatif

Cliquez sur le bouton "**Trésorerie**" dans le menu principal à gauche de la page.

Ensuite, cliquez sur "**Transactions**" puis sur le bouton représenté par la "**Lettre A**".

Enfin, dans la liste qui s'affiche, sélectionnez "**Aucun justificatif**".

## Statut de transaction

Quand vous aurez indiqué que la transaction n'a pas de justificatif, le statut de celle-ci va se mettre à jour en jaune "**Aucun justificatif**".
