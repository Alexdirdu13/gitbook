# À quoi correspondent les types de lettrage ?

## Type de lettrage

Le type de lettrage permet de définir s'il s'agit d'une facture ou d'une transaction bancaire, en débit ou en crédit.

Pour trouver le type de votre lettrage, cliquez sur "**Achats**" puis sur "**Lettrage**" dans le menu principal à gauche. Cliquez ensuite sur l'onglet **"Toutes les opérations"**.

Dans la barre de "**Recherche**" en haut, vous pouvez choisir le type de transaction que vous souhaitez.
