# Comment configurer sa fiche fournisseur

## Se rendre sur la liste des fournisseurs

Si vous en avez les droits, il vous est possible de configurer votre fiche fournisseur en y ajoutant des champs. Pour ce faire, rendez-vous dans votre liste de fournisseurs en cliquant sur "**Contacts**", puis "**Fournisseurs**". Cliquez ensuite sur l'onglet "**Champs fournisseur**".

## Configurer la fiche fournisseur

Vous serez alors redirigé vers la page de configuration fournisseur. Pour ajouter un champ à la fiche fournisseur, cliquez sur "**Ajouter un champ**", puis renseignez le libellé, indiquez si c'est un champ obligatoire, ainsi que le type de champ.
