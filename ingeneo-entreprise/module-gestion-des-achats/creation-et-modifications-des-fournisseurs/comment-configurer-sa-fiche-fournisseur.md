# Comment configurer sa fiche fournisseur

## Se rendre sur la liste des fournisseurs

Il vous est possible, si vous en avez les droits de configurer votre fiche fournisseur en ajouter des champs. Pour se faire, il vous faut vous rendre dans votre liste fournisseur en cliquant sur "**Contacts**", puis "**Fournisseurs**". Cliquez ensuite sur l'onglet "**Champs fournisseur**".

## Configurer la fiche fournisseur

Vous serez alors redirigé sur la page de configuration fournisseur. Pour ajouter un champ à la fiche fournisseur, cliquez sur "**Ajouter un champ**" puis remplissez le libellé, si c'est un champ obligatoire, ainsi que le type de champ.
