# Comment exporter la liste des Fournisseurs

## Sélectionner les fournisseurs à exporter

* Sélectionner l'onglet "Contact"
* Puis sélectionner "Fournisseurs"
* A l'aide de la colonne de sélection, sélectionner les clients souhaités

**Chemin : Suivant**

## Cliquer sur Export Excel

* Après avoir sélectionner les fournisserus, le bouton "Export Excel" apparait
* Cliquer sur "Export Excel"

**Chemin : Suivant**

## Téléchargement de l'export

* Après le clic sur "Export Excel", le fichier apparait dans les téléchargements
*   Le fichier comporte 3 onglets :

    Fournisseurs : Liste complète des entités sélectionnées avec leurs informations IBAN : Liste de tous les IBAN liés aux fournisseurs sélectionnés Contacts : Tous les contacts associés (nom, e-mail, téléphone…)
