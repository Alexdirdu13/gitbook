# Comment exporter la liste des fournisseurs

## Sélectionner les fournisseurs à exporter

* Sélectionnez l'onglet "Contact"
* Puis sélectionnez "Fournisseurs"
* À l'aide de la colonne de sélection, sélectionnez les fournisseurs souhaités

**Chemin : Suivant**

## Cliquer sur Export Excel

* Après avoir sélectionné les fournisseurs, le bouton "Export Excel" apparaît
* Cliquez sur "Export Excel"

**Chemin : Suivant**

## Téléchargement de l'export

* Après le clic sur "Export Excel", le fichier apparaît dans les téléchargements
* Le fichier comporte 3 onglets :
  * Fournisseurs : liste complète des entités sélectionnées avec leurs informations
  * IBAN : liste de tous les IBAN liés aux fournisseurs sélectionnés
  * Contacts : tous les contacts associés (nom, e-mail, téléphone…)
