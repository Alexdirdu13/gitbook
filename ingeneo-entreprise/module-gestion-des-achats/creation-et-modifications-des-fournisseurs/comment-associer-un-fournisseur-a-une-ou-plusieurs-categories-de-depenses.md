# Comment associer un fournisseur à une ou plusieurs catégories de dépenses ?

## Associer un fournisseur à un ou plusieurs catégories de dépenses

Afin de limiter les erreurs de ventilation des factures, vous pouvez associer un fournisseur à un ou plusieurs catégories de dépenses :

1. Onglet Comptabilité
2. Paramètres
3. Règles comptables achats
4. Ajouter

**Chemin : Ajouter une nouvelle règle comptable**

## Ajouter une nouvelle règle comptable

1. Sélectionner le fournisseur
2. Sélectionner la catégorie de dépense
3. Sélectionner le n° de compte du plan comptable

**À savoir :**

Vous pouvez ajouter autant de règles comptables que nécessaire pour le même fournisseur

**Chemin : Restreindre la configuration des écritures comptables selon les règles suivantes**

## Restreindre la configuration des écritures comptables

Vous pouvez restreindre la configuration des écritures comptables selon les règles afin que les utilisateurs ne puissent pas sélectionner une autre catégorie de dépense que celle définies en activant l'option

**Chemin : Modifier une règle comptable**

## Modifier une règle comptable

Vous pouvez modifier la règle comptable en cliquant sur le crayon
