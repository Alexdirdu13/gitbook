# Comment payer les fournisseurs directement depuis Qotid ?

## Payer les fournisseurs depuis Qotid

Quelles sont les conditions pour payer avec Qotid ?

Pour avoir le bouton "**PAYER**", vous devez :

* Avoir accès aux modules **Achats** et **Compte Pro Qotid**
* Avoir les **droits utilisateurs** pour payer

Il existe 2 méthodes pour payer vos fournisseurs depuis le module "Achats" :

* avec le Compte Pro Qotid
* en générant un fichier xml SEPA

**Chemin : Payer avec le Compte Pro Qotid**

## Payer avec le Compte Pro Qotid

Pour payer avec le Compte Pro Qotid, il faut que l'utilisateur ait 2 accès :
