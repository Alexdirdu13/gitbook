# Comment créer une adresse email qui permet de récupérer automatiquement vos factures par email ?

## Espace emails

Vous avez la possibilité sur Qotid de créer de nouvelles adresses qui viendront récupérer vos factures. Pour ce faire, cliquer sur le bouton "Paramètres" représenté par un engrenage puis cliquez sur "**Adresses email**".

## Créer un nouveau mail

Une page s'ouvrira. Il vous suffira de cliquer sur le bouton "**Ajouter**" pour créer un mail, cela ouvrira un pop-up, il vous suffira de remplir les champs souhaités : types, établissement, variable, et si vous souhaitez attribuer ce mail à un profil utilisateur créer au préalable.

Une fois tous les champs remplis, il vous suffit de cliquer sur "**Valider**" pour créer l'adresse mail.
