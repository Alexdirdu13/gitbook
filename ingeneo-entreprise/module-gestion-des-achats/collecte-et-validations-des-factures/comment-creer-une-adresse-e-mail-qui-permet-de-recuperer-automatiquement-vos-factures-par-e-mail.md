# Comment créer une adresse e-mail qui permet de récupérer automatiquement vos factures par e-mail ?

## Espace e-mails

Vous avez la possibilité, sur Qotid, de créer de nouvelles adresses qui viendront récupérer vos factures. Pour ce faire, cliquez sur le bouton "Paramètres" représenté par un engrenage, puis sur "**Adresses e-mail**".

## Créer une nouvelle adresse

Une page s'ouvrira. Il vous suffira de cliquer sur le bouton "**Ajouter**" pour créer une adresse : cela ouvrira un pop-up, dans lequel il vous suffira de remplir les champs souhaités (type, établissement, variable) et, si vous le souhaitez, d'attribuer cette adresse à un profil utilisateur créé au préalable.

Une fois tous les champs remplis, il vous suffit de cliquer sur "**Valider**" pour créer l'adresse e-mail.
