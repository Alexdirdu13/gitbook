# Comment ventiler une transaction dans plusieurs catégorie de trésorerie ?

## Ventiler une transaction

![Capture d'écran](../../.gitbook/assets/ventiler-transaction-1.png)

Pour ventiler une transaction, il faut se rendre dans **Trésorerie / Transactions.**

Il faut repérer une transaction que vous souhaitez ventiler dans plusieurs catégorie de trésorerie.

Ensuite vous pouvez cliquez sur **Ventiler la transaction**

## Ventiler la transaction - Etape 2

![Capture d'écran](../../.gitbook/assets/ventiler-transaction-2.png)

Ensuite vous arrivez sur une popup sur laquelle vous pouvez :

1. Ajouter des ventilations
2. Ajuster le montant de chaque ventilation
3. Catégoriser chaque ventilation dans des catégories précises
4. Valider votre ventilation

**À savoir :**

Un détail de votre ventilisation est disponible vus indiquant :

* Le montant déjà réparti
* Le montant d'origine
* Différence

La différence doit être égale à 0 pour valider votre ventilation.

**Dans le cas oui le montant de vos ventilations n'est pas égale au montant total de la transaction d'origine, vous ne pourrez pas valider votre ventilation.**
