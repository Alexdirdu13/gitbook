## Comment afficher l'ensemble de vos établissements sur une visualisation du tableau de bords

Pour les groupes multi-entités, vous pouvez afficher l'ensemble de vos établissements sur une visualisation. Il existe deux possibilités :

* via l'onglet Compte de résultat sous format P\&L
* via les tableaux de bords

Nous vous expliquons dans cette vidéo comment le faire dans l'onglet tableau de bords.

**À savoir :** Vous pouvez cliquer sur le bouton **Suivant** pour voir la vidéo concernant l'ajout d'une visualisation multi-établissements sous format P\&L
