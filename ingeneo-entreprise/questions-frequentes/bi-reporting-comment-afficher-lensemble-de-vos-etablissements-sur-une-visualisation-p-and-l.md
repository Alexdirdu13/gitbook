# \[BI REPORTING] Comment afficher l'ensemble de vos établissements sur une visualisation P\&L ?

## Comment afficher l'ensemble des vos établissements sur une visualisation P\&L ?

Pour les groupes multi-entités, cette vidéo vous explique comment vous pouvez afficher l'ensemble de vos établissements sur une visualisation. Il existe deux possibilités :

* une via les Reportings sous format P\&L
* une via les tableaux de bords

Nous vous expliquons dans cette vidéo comment le faire dans l'onglet P\&L.

**À savoir :** Vous pouvez cliquer sur le bouton **Suivant** pour voir la vidéo concernant l'ajout d'une visualisation multi-établissements sous format Tableau de bords
