# Comment payer mes factures fournisseurs en générant un fichier xml SEPA ?

## Sélectionner les factures à payer

Pour payer vos factures fournisseur en générant un fichier xml SEPA, aller dans :

1. Achats : Factures (ou Validation de factures)
2. Onglet "A payer" ou "En retard"
3. Sélectionner les factures à régler
4. Visualisation du montant total de la sélection
5. Cliquer sur le bouton "**Payer**"

## Nouveau virement

Une nouvelle fenêtre s'ouvre pour générer le xml SEPA.

1. Vous pouvez visualiser le compte qui sera indiqué sur le xml SEPA (il s'agit du compte renseigné dans la gestion de l'établissement)
2. Les montants se mettent automatiquement
3. Les IBANS sont reconnus automatiquement sur la facture ou si la fiche société est complété. Vous pouvez corriger les iban fournisseur
4. Une fois les paramètres renseignés, vous pourrez cliquer sur le bouton "**Générer le fichier SEPA**".

## Type de fichier XML SEPA

Vous pouvez générer le fichier détaillé ou global :

* par transactions détaillées : facilite le lettrage
* montant global : permet de n'avoir qu'une seule ligne sur le compte
