# Comment payer mes factures fournisseurs directement avec mon compte Pro Qotid ?

## Solde du compte Pro Qotid

Tout d'abord, s'assurer que le solde du Compte Pro Qotid soit suffisamment approvisionné : pour vérifier le solde

* Compte Pro
* Paramètres
* Solde disponible

**Attention :**

Il n'est pas possible de faire des virements supérieurs au solde, le compte Pro Qotid ne peut pas être débiteur

**Chemin : Payer mes factures**

## Paiement des factures

Pour payer vos factures fournisseur avec votre compte Pro Qotid, aller dans :

1. Achats : Factures (ou Validation de factures)
2. Onglet "A payer"
3. Sélectionner les factures à régler
4. Visualisation du montant total de la sélection
5. Cliquer sur le bouton "**Payer**"

## Nouveau virement

Une nouvelle fenêtre s'ouvre pour programmer le virement.

1. Vous pouvez visualiser le solde de votre compte pro Qotid et voir si les fonds sont suffisants pour payer vos factures
2. Les montants se mettent automatiquement
3. Les IBANS sont reconnus automatiquement sur la facture ou si la fiche société est complété. Vous pouvez corriger les iban fournisseur
4. Le libellé se met par défaut avec nom du fournisseur + N° de la facture. Vous pouvez le personnaliser
5.  Vous pouvez planifiez votre virement :

    le jour même à une date ultérieure à la date d'échénace de la facture instantanément
6.  Une fois les paramètres renseignés, vous pourrez cliquer sur le bouton "**Payer avec ce compte**". Il faudra valider l'opération avec votre téléphone.

    **À savoir :**

    Lorsque vous payez avec le compte Pro Qotid, le lettrage se fait automatiquement

## Liste des virements

Vous pourrez ensuite vous rendre dans l'onglet Compte Pro/Virement pour consulter la liste de tous les virements Planifié/en cours/fait etc...
