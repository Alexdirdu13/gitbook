# Que signifie le statut "Les informations ne correspondent pas" sur le compte Pro ?

## Statut compte Pro

Si vous avez ouvert un compte Pro Qotid et créé un utilisateur dont le statut indique "**Les informations ne correspondent pas**" alors cela signifie que les informations renseignées lors de la création de l'utilisateur ne correspondent pas aux informations mentionnées sur la pièce d'identité ou saisie par l'utilisateur lui même.

Pour modifier ces informations, vous pouvez cliquer sur le bouton **Gestion du compte** en haut de l'écran.

## Modifier les informations

Vous serez ensuite redirigé vers votre interface bancaire.

Cliquer ensuite sur la rubrique **Membres** puis cliquer sur le nom de l'utilisateur dont le statut n'est pas Actif.

## Vérifier les informations

Une fenêtre s'ouvre mentionnant l'ensemble des informations fournies à la création du compte.

Vérifiez que toutes les informations correspondent à ce qui est mentionné sur la pièce d'identité (Vérifiez bien notamment à compléter l'ensemble des prénoms, date de naissance, etc.).

Une fois les informations corrigées, vous pouvez cliquer sur **Sauvegarder**.
