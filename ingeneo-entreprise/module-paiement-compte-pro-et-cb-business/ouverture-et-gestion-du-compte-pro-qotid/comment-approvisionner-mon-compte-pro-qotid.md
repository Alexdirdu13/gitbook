# Comment approvisionner mon compte Pro Qotid ?

## Approvisionnement du Compte Pro Qotid

Pour approvisionner le compte Pro Qotid, il y a 2 possibilités :

* Approvisionnement manuel
* Approvisionnement automatique

**Chemin : Approvisionnement manuel**

## Approvisionnement manuel

Pour approvisionner mon Compte Pro Qotid manuellement, je retrouve les informations de mon compte dans :

1. Compte Pro - Paramètres
2. Information du compte
3. Je retrouve les informations bancaires de mon compte Pro Qotid pour pouvoir faire un virement depuis mon compte bancaire

**Chemin : Approvisionnement automatique**

## Générer le mandat du réapprovisionnement automatique

Il est possible d'automatiser l'approvisionnement de mon compte Pro Qotid.

1. Compte Pro - Paramètres
2. Gestion du réapprovisionnement : Autorisation
3. Ajouter un compte à débiter
4. Compléter les informations du compte bancaires à débiter - Générer l'autorisation à signer et à envoyer à votre banque

## Paramétrer les conditions du réapprovisionnement automatique

1. Compte Pro / Paramètres
2. Gestion du réapprovisionnement / Réapprovisionnement automatique
3. Créer le réapprovisionnement automatique (tant que le mandat n'est pas validé, le bouton ne sera pas disponible)
4.  Renseigner les conditions du réapprovisionnement :

    Seuil de déclenchement : le compte principal sera débité lorsque le solde du compte Pro descendra en dessous du montant spécifié Montant du réapprovisionnement : dès que le seuil sera déclenché, le compte sera approvisionné de ce montant

**À savoir :**

Dans l'exemple : dès que le compte descendra en dessous de 10.000€, un virement depuis le compte bancaire sera effectué de 20.000€

**Attention :**

Vous ne pouvez pas effectuer plus de 5 prélèvements par mois, il faut donc paramétrer un montant suffisant pour couvrir vos factures du mois

**A NOTER** : le réapprovisionnement automatique prévoit un délai de 5 à 7 jours pour que les fonds arrivent sur le compte
