# Comment télécharger les relevés bancaires de votre compte Pro ?

## Télécharger le relevé bancaire de votre compte Pro

Pour télécharger le relevé de votre compte Pro Qotid, il faut se rendre sous **Compte Pro**, puis **Transactions**, et cliquer sur **Relevés de compte**.

**Chemin : Suivant**

## Configuration de la date et du format d'export

Il vous suffira ensuite de choisir :

* Une date de début
* Une date de fin
* Le format d'export : PDF ou CSV

Puis cliquez sur **Générer**.

**Attention :**

Nous vous conseillons de transmettre les informations en CSV à votre comptable. Cela l'aidera à intégrer le fichier en comptabilité.

**À savoir :**

Si le fichier PDF a déjà été téléchargé, il s'ouvrira dans un onglet. Si le fichier CSV a déjà été téléchargé, il se téléchargera directement dans votre navigateur.

**Dans le cas contraire, vous recevrez un e-mail avec un lien permettant de télécharger le document.**
