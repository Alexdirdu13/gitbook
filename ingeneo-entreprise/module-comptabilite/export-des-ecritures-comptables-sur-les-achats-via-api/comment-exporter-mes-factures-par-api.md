# Comment exporter mes factures par API ?

## Exporte en des factures par API

Il existe deux possibilités pour exporter vos factures par API :

* En masse
* Facture par facture

**Chemin : Exporter en masse mes factures par API**

## Exporter en masse les écritures comptables de mes factures via API

1. Se rendre sur **Comptabilité / Comptabilité Fournisseur ou Client ou Banque**
2. Se rendre dans le bloc **Traité** et cocher les factures que vous souhaitez envoyer en comptabilité
3. Cliquez sur **Export comptable via API**

**À savoir :**

Une fois l'export réalisé, la facture passe directement en statut **Traité**

**Chemin : Exporter facture par facture via API**

## Exporter facture par facture mes écritures comptables via API

Pour exporter vos écritures comptables facture par facture, il faut:

1. Se rendre sur **Comptabilité / Comptabilité Fournisseur ou Client ou Banque**
2. Se rendre dans le bloc **Traité** et cliquer sur la facture que vous souhaitez envoyer en comptabilité
3. Cliquez sur **Export comptable via API**

**À savoir :**

Une fois l'export réalisé, la facture passe directement en statut **Traité**
