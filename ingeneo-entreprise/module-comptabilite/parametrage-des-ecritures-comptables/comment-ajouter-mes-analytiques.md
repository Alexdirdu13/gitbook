# Comment ajouter mes analytiques ?

## Mes analytiques

Cliquez sur le bouton "**Achat**" dans le menu principal à gauche de la page, puis cliquez sur "**Paramètres**".

Une nouvelle fenêtre s'ouvrira, cliquez sur le bouton "**Analytiques**" en haut, puis cliquez sur le bouton "**Ajouter**" à droite.

**À savoir :**

Attention : cette fonctionnalité est payante et doit être activée par votre chargé de compte Qotid pour y accéder.

## Ajouter une analytique

Une nouvelle fenêtre s'ouvrira, remplissez le champs puis cliquez sur le bouton "**Ajouter**" pour valider votre choix.
