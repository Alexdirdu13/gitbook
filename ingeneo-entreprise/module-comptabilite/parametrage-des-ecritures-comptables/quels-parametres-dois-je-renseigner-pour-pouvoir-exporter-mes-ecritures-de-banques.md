# Quels paramètres dois-je renseigner pour pouvoir exporter mes écritures de banques ?

## Paramétrage comptabilité bancaire

Plusieurs paramètres sont à renseigner avant de pouvoir exporter les écritures comptables liées aux transactions bancaires.

Pour cela, vous pouvez vous rendre dans l'onglet Comptabilité / Paramètres / Comptabilité bancaire.

## Code journal

1. Vous devez renseigner le code journal correspondant à celui paramétré dans votre logiciel comptable.
2. Vous pouvez spécifier un compte comptable par défaut pour le compte de contrepartie (401000 - fournisseur, par exemple).

Une fois renseigné, vous pouvez cliquer sur le bouton **Enregistrer**.

## Compte comptable

Vous devez ensuite renseigner le compte comptable correspondant à chaque compte bancaire (compte 512000 - Compte Pro Qotid, par exemple).

Pour cela, il suffit de cliquer sur le stylo à droite de la ligne, puis de cliquer sur le bouton **Enregistrer**.

## Modèle d'export

Vous pourrez vous rendre dans l'onglet **Export comptable bancaire** pour sélectionner et personnaliser le modèle d'export correspondant à votre logiciel comptable.
