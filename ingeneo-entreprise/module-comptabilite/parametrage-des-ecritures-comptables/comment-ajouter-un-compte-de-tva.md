# Comment ajouter un compte de TVA ?

## Ajouter un compte de TVA

Cliquez sur le bouton "**Achat**" dans le menu principal à gauche de la page, puis cliquez sur "**Paramètres**".

Une nouvelle fenêtre s'ouvrira, cliquez sur le bouton "**TVA**" en haut, puis cliquez sur le bouton "**Ajouter**" à droite.

## Saisie du compte TVA

Une nouvelle fenêtre s'ouvrira, remplissez les champs et cliquez sur le bouton "**Ajouter**" afin de créer un nouveau compte de TVA.
