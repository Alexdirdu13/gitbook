# Comment ajouter des catégories dépenses ?

## Trouver la catégorie dépenses

Cliquez sur le bouton "**Comptabilité**" dans le menu principal à gauche de la page, puis cliquez sur "**Paramètres**".

Une nouvelle fenêtre s'ouvrira, cliquez sur le bouton "**Catégories dépenses**", puis cliquez sur le bouton "**Ajouter**" à droite.

## Ajouter la catégorie dépense

* Une nouvelle fenêtre s'ouvrira, ajoutez la catégorie de dépense souhaitée dans la case, puis cliquez sur le bouton "**Valider**".
