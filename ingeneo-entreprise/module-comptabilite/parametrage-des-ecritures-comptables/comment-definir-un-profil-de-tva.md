# Comment définir un profil de TVA ?

## Profils de TVA

Cliquez sur le bouton "**Achat**" dans le menu principal à gauche de la page, puis cliquez sur "**Paramètres**".

Une nouvelle fenêtre s'ouvrira : cliquez sur le bouton "**TVA**" en haut, puis cliquez sur le bouton "**Profils**" à droite.

**À savoir :**

Attention : cette fonctionnalité doit être activée pour y accéder.

## Définir le profil TVA

Une fenêtre s'ouvrira, vous permettant d'ajouter le profil de TVA souhaité. Remplissez les champs et cliquez sur "**Ajouter**" pour valider.
