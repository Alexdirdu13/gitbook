# Comment définir le code journal ?

## Définir un code journal

Cliquez sur le bouton "**Achat**" dans le menu principal à gauche de la page, puis cliquez sur "**Paramètres**".

Une nouvelle fenêtre s'ouvrira, cliquez sur le bouton "**Code journal**" en haut, choisissez le code journal souhaité dans le libellé puis cliquez sur le bouton "**Sauvegarder**" à droite pour valider votre choix.
