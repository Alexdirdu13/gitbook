# Comment annuler les écritures comptables qui ont déjà été exportées ?

## Ouvrir l'onglet Comptabilité fournisseurs

Cliquez sur le bouton "**Comptabilité**" dans le menu principal à gauche de la page, puis cliquez sur "**Comptabilité fournisseurs**".

## Aller dans le statut exporté

Cliquez sur le bouton "**Exporté**"

Vous verrez afficher l'intégralité des factures dont les écritures ont déjà été exportées.

## Utiliser les recherches en en-tête

Vous pouvez-utiliser les différentes recherches en en-tête des colonnes pour retrouver les documents pour lesquels vous voulez régénérer les écritures comptables.

**À savoir :**

Vous pouvez utiliser la date d'export, le nom du fournisseur, numéro de facture, etc....

## Régénérer les écritures d'une facture

Pour que les écritures comptables de votre facture soit de nouveau présentes dans l'onglet "Export comptable", il vous suffit de cliquer sur la flèche.

**À savoir :**

En cliquant sur le bouton, nous vous expliquons comment vous pouvez annuler l'export de plusieurs factures à la fois

## Régénérer les écritures de plusieurs factures en masse

Pour que les écritures comptables de vos factures soit de nouveau présentes dans l'onglet "export comptable", il vous suffit de sélectionner plusieurs factures puis de cliquer sur **"supprimer Annuler l'export des écritures et la validation comptable"**

## Retourner dans Export comptable pour télécharger ces écritures de nouveau

Vous n'avez plus qu'a exporter vos écritures comptables en retournant dans l'onglet "export"

Celles-ci seront de nouveau présentes une fois ces factures repassé dans le statut traité dans l'onglet comptabilité fournisseurs
