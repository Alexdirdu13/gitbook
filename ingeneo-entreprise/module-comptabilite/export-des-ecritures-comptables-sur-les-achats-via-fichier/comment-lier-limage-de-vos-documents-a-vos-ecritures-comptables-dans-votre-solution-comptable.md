# Comment lier l'image de vos documents à vos écritures comptables dans votre solution comptable ?

## Paramètrage de son export comptable

Pour lier l'image de vos documents à vos écritures comptables, la première chose à faire est de paramétrer correctement votre modèle d'export avec le champs **Fichier PDF (avec extension)** qui sera indispensable pour lier les documents avec l'écritures comptables.

Pour cela vous pouvez aller dans **Comptabilité** puis **Paramètres.**

**Attention :**

Vous devez avoir les autorisations de votre administrateur de compte pour faire cette modification

## Paramètrage de l'export comptable

Cliquez sur l'onglet **Modèles d'export comptable**

## Paramètrage de l'export comptable

Vous arrivez sur les paramètrages de votre export comptable, cliquer sur **Ajouter**

## Champs Fichier PDF (avec extension)

Sélectionnez le champs **Fichier PDF (avec extension)**

## Positionnez le champs ou vous souhaitez dans votre modèle d'expor

Le champs apparaît dans la liste de vos éléments à exporter dans votre modèle d'export.

Si besoin vous pouvez le déplacer dans le champs de votre choix.

## Export avec lien du document

Maintenant si vous retournez dans Comptabilité puis Export comptable et que vous tentez d'exporter vos écritures comptables, vous constaterez que le nom du fichier est attaché à l'écriture comptable dans le champs correspondant.

Vous pouvez maintenant télécharger l'export avec les documents.

**Attention :**

Le modèle d'export avec les documents doit être compatible avec le modèle d'import accepté par votre logiciel comptable.

**Veuillez vous approchez du vendeur ou support du logiciel comptable que vous utilisez pour connaitre le modèle d'import autorisé.**

Si besoin Qotid peut également vous apporter votre aide en contactant le support directement.
