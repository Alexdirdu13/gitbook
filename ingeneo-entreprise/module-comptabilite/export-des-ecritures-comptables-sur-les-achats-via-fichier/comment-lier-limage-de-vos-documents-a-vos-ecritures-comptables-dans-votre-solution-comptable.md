# Comment lier l'image de vos documents à vos écritures comptables dans votre solution comptable ?

## Paramétrage de son export comptable

Pour lier l'image de vos documents à vos écritures comptables, la première chose à faire est de paramétrer correctement votre modèle d'export avec le champ **Fichier PDF (avec extension)**, qui sera indispensable pour lier les documents aux écritures comptables.

Pour cela, vous pouvez aller dans **Comptabilité**, puis **Paramètres**.

**Attention :**

Vous devez avoir les autorisations de votre administrateur de compte pour faire cette modification.

## Paramétrage de l'export comptable

Cliquez sur l'onglet **Modèles d'export comptable**.

## Paramétrage de l'export comptable

Vous arrivez sur les paramétrages de votre export comptable : cliquez sur **Ajouter**.

## Champ Fichier PDF (avec extension)

Sélectionnez le champ **Fichier PDF (avec extension)**.

## Positionner le champ où vous le souhaitez dans votre modèle d'export

Le champ apparaît dans la liste de vos éléments à exporter dans votre modèle d'export.

Si besoin, vous pouvez le déplacer à l'endroit de votre choix.

## Export avec lien du document

Maintenant, si vous retournez dans Comptabilité, puis Export comptable, et que vous tentez d'exporter vos écritures comptables, vous constaterez que le nom du fichier est attaché à l'écriture comptable dans le champ correspondant.

Vous pouvez maintenant télécharger l'export avec les documents.

**Attention :**

Le modèle d'export avec les documents doit être compatible avec le modèle d'import accepté par votre logiciel comptable.

**Veuillez vous rapprocher du vendeur ou du support du logiciel comptable que vous utilisez pour connaître le modèle d'import autorisé.**

Si besoin, Qotid peut également vous apporter son aide : contactez directement le support.
