# Comment exporter mes écritures comptables AVEC les documents ?

## Ouvrir la fenêtre d'export

Cliquez sur le bouton "**Comptabilité**" dans le menu principal à gauche de la page, puis cliquez sur "**Export comptable**".

**Attention :**

**Votre administrateur de compte doit vous avoir donné les autorisations pour accéder à cette page.**

## Statut par défaut

Par défaut, vous ne pouvez exporter que les factures qui sont dans le statut "Traité" dans l'onglet Comptabilité fournisseur.

## Affichage des écritures comptables en fonction du modèle d'export choisi

Les écritures comptables sont mises à jour en fonction du modèle d'export sélectionné.

## Exporter les écritures

Une fois le modèle d'export sélectionné :

Cliquez sur le bouton "**Télécharger**" à droite et sélectionnez "**Télécharger avec les documents**" afin de finaliser l'export des écritures.

Un fichier contenant le document d'écriture comptable va se télécharger sur votre ordinateur.

**À savoir :**

Les écritures exportées ne sont plus exportables, sauf si vous annulez l'export.
