# Comment créer un champ personnalisé dans mon export comptable ?

## Configuration de l'export comptable

Cliquez sur le bouton "**Comptabilité**" dans le menu principal à gauche de la page, puis cliquez sur "**Paramètres**" et sélectionnez "**Modèles d'export comptable**".

Puis cliquez sur le bouton "**Ajouter**" à droite.

## Ajouter un champ

Une nouvelle fenêtre s'ouvrira : sélectionnez le champ et remplissez les informations nécessaires.

Une fois les informations remplies, cliquez sur "**Valider**" pour finaliser la création.
