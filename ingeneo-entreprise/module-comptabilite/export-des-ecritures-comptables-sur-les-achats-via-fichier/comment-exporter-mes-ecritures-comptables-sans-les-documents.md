# Comment exporter mes écritures comptables SANS les documents ?

## Ouvrir la fenêtre d'export

Cliquez sur le bouton "**Comptabilité**" dans le menu principal à gauche de la page, puis cliquez sur "**Export comptable**".

**Attention :**

**Attention votre administrateur de compte doit vous avoir donner les autorisations pour accéder à cette page.**

## Statut par défaut

Par défaut, vous ne pouvez exporter que les factures qui sont dans le statut "Traité" dans l'onglet Comptabilité fournisseur.

## Affichage des écritures comptables en fonction du statut choisi

Les écritures comptables sont mises à jours en fonction du modèle d'export sélectionné.

## Exporter les écritures

Une fois le ou les statuts sélectionnés:

Cliquez sur le bouton "**Télécharger**" à droite et sélectionnez "**Télécharger sans les documents**" afin de finaliser l'export des écritures.

Un fichier ZIP avec les documents PDF et le document d'écriture comptable va se télécharger sur votre ordinateur.

**À savoir :**

Les écritures exportées ne sont plus exportables sauf si vous annulez l'export.
