# Comment réorganiser les champs dans mon export comptable ?

## Configuration de l'export comptable

Cliquez sur le bouton "**Comptabilité**" dans le menu principal à gauche de la page, puis cliquez sur "**Paramètres**".

Une nouvelle fenêtre s'ouvrira : cliquez sur le bouton "**Modèles d'export comptable**", puis cliquez sur le bouton avec les **trois traits** à droite.

## Réorganiser les champs

Une nouvelle fenêtre s'ouvrira : déplacez le curseur de votre souris sur les **six points** à gauche des champs. Maintenez le clic appuyé, puis déplacez les champs selon l'organisation que vous souhaitez et cliquez sur "**Valider**".
