# Comment rappeler une note de frais soumise ?

## Pourquoi rappeler une note de frais

Lorsque vous avez soumis votre note de frais, elle passe au statut « à approuver ». Il peut arriver que vous vous soyez trompé au moment de la soumission, parce que vous avez oublié quelque chose.

## Rappeler la note de frais

Tant que la note n'a pas encore été validée par quelqu'un (elle peut soit être validée, soit être refusée), vous pouvez la rappeler :

1. Retrouvez la note de frais dans la liste, au statut « à approuver ».
2. Cliquez sur **Rappeler**, directement depuis la liste ou en ouvrant la note.
3. La note de frais retourne dans les **brouillons** : vous pouvez ensuite la modifier.

## Cas d'une note refusée

{% hint style="warning" %}
**Attention :** vous ne pouvez plus modifier une note de frais refusée définitivement. Vous pouvez modifier uniquement les notes refusées pour lesquelles la personne qui a refusé vous autorise la correction.
{% endhint %}
