# Comment fonctionne la détection des doublons ?

## Principe

Qotid gère les **doublons** sur les notes de frais. Que vous déposiez le même document dans une même note de frais ou dans différentes notes de frais, l'application vous indique si la dépense apparaît comme étant un doublon.

## Que faire en cas de doublon

Si une dépense est signalée comme doublon, vous pouvez, le cas échéant, la **supprimer** pour éviter de déposer des documents en double.
