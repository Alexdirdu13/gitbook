# Comment ajouter des dépenses dans une note de frais ?

## Principe

Une fois votre note de frais créée, vous pouvez y ajouter des dépenses. Cet article présente le dépôt d'une dépense classique. Vous pouvez aussi ajouter des indemnités kilométriques : voir [Comment ajouter une indemnité kilométrique ?](../mise-en-place-et-parametrage/comment-ajouter-une-indemnite-kilometrique.md).

## Ajouter une dépense avec un justificatif

1. Dans la note de frais, ajoutez une dépense.
2. Sélectionnez votre ticket de caisse. Sur téléphone portable, l'application vous demande de prendre une **photo** directement.
3. La dépense remonte directement dans la note de frais.

Vous pouvez ajouter **plusieurs dépenses** à l'intérieur d'une même note avant de la soumettre en validation.

## Compléter la dépense

En entrant dans la dépense, vous pouvez :

* Enregistrer un **motif** concernant la dépense.
* Définir le **type de frais** (par exemple restaurant) si le système ne l'a pas reconnu.
* **Vérifier que le montant est correct**, puis enregistrer la dépense.
