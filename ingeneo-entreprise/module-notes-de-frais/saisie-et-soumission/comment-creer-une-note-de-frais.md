# Comment créer une note de frais ?

## Avant de commencer

Pour pouvoir déposer des notes de frais, le paramétrage comptable doit être fait et les droits de vos collaborateurs doivent être gérés (qui peut déposer, valider ou payer). Voir [Comment gérer les collaborateurs et activer les licences notes de frais ?](../mise-en-place-et-parametrage/comment-gerer-les-collaborateurs-et-activer-les-licences-notes-de-frais.md).

## Ce qu'il faut comprendre

Une note de frais peut contenir **plusieurs dépenses** avant d'être soumise en validation, le cas échéant.

## Créer une note de frais

1. Cliquez sur **Ajouter une note de frais**.
2. Qotid renseigne automatiquement le **mois en cours** comme nom de la note. Vous pouvez le modifier.
3. Ajoutez ensuite les dépenses dans cette note de frais.
