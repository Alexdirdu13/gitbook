# Comment valider une note de frais ?

## Accéder à l'écran de validation

Si vous avez les droits de validation, un écran vous permet de valider les notes de frais. Il présente dans des encarts les notes de frais à approuver, celles que vous avez approuvées, etc.

## Valider une note de frais

1. Cliquez sur la note de frais à approuver.
2. Consultez les **dépenses** qu'elle contient.
3. **Validez** la note de frais (ou refusez-la : voir [Comment refuser une note de frais ?](comment-refuser-une-note-de-frais.md)).

## Après la validation

Une fois la note validée, elle apparaît dans l'encart **« Approuvé »**. Le collaborateur voit que sa note de frais est **approuvée**.
