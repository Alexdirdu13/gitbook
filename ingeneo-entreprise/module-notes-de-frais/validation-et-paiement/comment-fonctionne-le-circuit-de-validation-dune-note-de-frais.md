# Comment fonctionne le circuit de validation d'une note de frais ?

## Qu'est-ce que le circuit de validation

Le circuit de validation (ou circuit d'approbation) définit **qui valide les notes de frais** d'un collaborateur.

Vous le définissez sur chaque collaborateur. Voir aussi [Comment gérer les collaborateurs et activer les licences notes de frais ?](../mise-en-place-et-parametrage/comment-gerer-les-collaborateurs-et-activer-les-licences-notes-de-frais.md).

## Deux possibilités de base

Quand le collaborateur soumet une note de frais :

* soit il **valide automatiquement** ses notes de frais ;
* soit une personne avec le **droit de validation** doit valider la note de frais.

Dans ces règles de base, toutes les personnes disposant d'un droit de validation peuvent valider les notes de frais de n'importe quel collaborateur.

## Circuits plus avancés

Il existe des circuits plus avancés, qui permettent de créer des règles précises sur **qui peut valider** quoi.
