# Comment payer une note de frais ?

## Principe

Une fois la note de frais **approuvée**, vous pouvez rembourser votre collaborateur, soit en masse en sélectionnant toutes les notes de frais à rembourser, soit note par note.

{% hint style="warning" %}
**Attention :** pour payer, il faut avoir le droit de paiement sur les notes de frais. Voir [Comment gérer les collaborateurs et activer les licences notes de frais ?](../mise-en-place-et-parametrage/comment-gerer-les-collaborateurs-et-activer-les-licences-notes-de-frais.md).
{% endhint %}

## Préparer les virements

1. Sélectionnez les notes de frais à rembourser.
2. Cliquez sur **Préparer les virements**.
3. Qotid affiche le montant à rembourser. Dans l'exemple de la vidéo, la note de frais est de 180 € dont 151,50 € sont remboursables, car une dépense a été faite avec la carte professionnelle (voir [Comment gérer les notes de frais avec une carte professionnelle ?](../cartes-professionnelles/comment-gerer-les-notes-de-frais-avec-une-carte-professionnelle.md)).

## Ajouter le RIB du collaborateur

Si le RIB du collaborateur n'a pas été enregistré, Qotid vous propose de l'ajouter. Vous pouvez ensuite sortir le **fichier SEPA**.

## Payer avec le Compte Pro

Si vous payez à travers le Compte Pro, la manipulation est la même, sauf que vous payez **directement dans l'application**.

{% hint style="info" %}
**À savoir :** pour payer avec le Compte Pro, des droits de paiement sont aussi nécessaires sur le compte bancaire lui-même. Pensez à consulter les articles du module Paiement concernant le Compte Pro, par exemple [Comment payer mes factures fournisseurs directement avec mon compte Pro Qotid ?](../../module-paiement-compte-pro-et-cb-business/paiements-des-factures-dachats-et-virements-depuis-le-compte-pro-qotid/comment-payer-mes-factures-fournisseurs-directement-avec-mon-compte-pro-qotid.md).
{% endhint %}
