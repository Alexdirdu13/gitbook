# Comment refuser une note de frais ?

## Principe

Une personne qui a le droit de **valider** une note de frais a aussi le droit de la **refuser**.

## Refuser une note de frais

1. Dans l'écran de validation, repérez la note de frais à approuver.
2. Ouvrez la note de frais.
3. Cliquez sur le bouton **Refuser**.

Vous avez alors deux possibilités.

### Demander un correctif

Vous autorisez la note de frais à repartir au statut **brouillon** chez la personne qui l'a soumise, pour qu'elle puisse faire les changements nécessaires.

Le collaborateur peut de nouveau soumettre sa note de frais, et il voit le **motif du refus**.

Si la note est soumise une deuxième fois, la personne qui revalide peut cette fois l'accepter, ou la refuser.

### Refuser définitivement

Vous refusez définitivement la note de frais en indiquant un **motif**.

{% hint style="warning" %}
**Attention :** si vous refusez définitivement une note de frais, elle n'est plus modifiable.
{% endhint %}

Le collaborateur voit alors que sa note de frais est **refusée** et peut voir pourquoi.
