# Comment paramétrer les comptes comptables de TVA ?

## Pourquoi paramétrer la TVA

Pour faciliter le travail de votre expert-comptable et qu'il récupère vos notes de frais avec les bonnes écritures, vous pouvez paramétrer la **TVA** sur les notes de frais.

## Définir un compte comptable par code de TVA

En face de chaque code de TVA, vous pouvez définir un **code comptable** correspondant à la TVA.

Cliquez sur le petit **crayon** pour le modifier.

## Créer d'autres taux de TVA

Si vous souhaitez créer d'autres taux de TVA avec des libellés différents :

1. Cliquez sur le bouton d'ajout.
2. Définissez un **libellé**.
3. Choisissez le **taux de TVA** associé à ce libellé.
4. Indiquez le **compte comptable** en face.

{% hint style="info" %}
**À savoir :** les libellés que vous créez sont ceux que l'utilisateur retrouvera au niveau de la note de frais, lorsqu'il sélectionnera la TVA.
{% endhint %}
