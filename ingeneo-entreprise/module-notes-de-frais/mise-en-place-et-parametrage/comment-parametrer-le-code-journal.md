# Comment paramétrer le code journal ?

## Paramétrer le code journal

Une fois les types de frais et la TVA paramétrés, il reste à paramétrer le **code journal** des notes de frais. Il doit correspondre à ce que vous avez en comptabilité pour les notes de frais.

Par exemple, vous pouvez indiquer le code **AC**.
