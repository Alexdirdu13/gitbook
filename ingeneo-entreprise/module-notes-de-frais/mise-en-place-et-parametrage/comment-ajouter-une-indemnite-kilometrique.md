# Comment ajouter une indemnité kilométrique ?

## Principe

Au même titre que l'ajout d'un reçu, vous pouvez ajouter des **indemnités de frais kilométriques** à une note de frais.

{% hint style="info" %}
**À savoir :** la note de frais doit être encore au statut **brouillon**.
{% endhint %}

## Ajouter un frais kilométrique

1. Ouvrez votre note de frais au statut brouillon.
2. Cliquez sur **Ajouter une dépense**.
3. Choisissez **Ajouter un frais kilométrique**.

## Ajouter un véhicule

Vous pouvez ensuite ajouter un véhicule :

1. Donnez-lui un nom.
2. Indiquez son type. Pour une voiture, le calcul se fait sur le **barème Urssaf**.
3. Renseignez la puissance (par exemple 4 chevaux).
4. Indiquez le nombre de kilomètres **déjà déclarés hors de l'application**, si vous êtes en migration. Si c'est la première fois que vous faites des kilomètres, indiquez **0**.
5. Cliquez sur **Ajouter le véhicule**.

{% hint style="warning" %}
**Attention :** le nombre de kilomètres déjà déclarés est important pour le calcul de l'indemnité.
{% endhint %}

## Saisir le trajet

1. Sélectionnez le motif du trajet (par exemple un voyage au bureau).
2. Renseignez le nombre de kilomètres parcourus.
3. Indiquez la date du voyage.
4. Qotid affiche une **estimation de l'indemnité** calculée.
5. Cliquez sur **Ajouter le frais kilométrique**.
