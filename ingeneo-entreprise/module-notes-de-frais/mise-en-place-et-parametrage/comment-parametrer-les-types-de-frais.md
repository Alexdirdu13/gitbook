# Comment paramétrer les types de frais ?

## Pourquoi paramétrer les types de frais

La première chose que vos collaborateurs font lorsqu'ils déposent une note de frais est de définir **de quel type de frais** il s'agit.

Par défaut, un certain nombre de catégories sont déjà paramétrées dans l'application, comme l'avion, le carburant ou les frais kilométriques. Des **comptes comptables** sont aussi paramétrés par défaut sur chacune d'elles.

## Vérifier les comptes comptables

Avant de commencer, vérifiez que les comptes comptables correspondent bien à votre plan comptable.

Si besoin, cliquez sur le **crayon** en face du type de frais pour modifier le compte.

## Définir le pourcentage de TVA récupérable

Un paramètre permet également de définir le **pourcentage de TVA récupérable** pour chaque type de frais.

Par exemple, si vous ne devez pas récupérer 100 % de la TVA mais seulement 80 %, indiquez **80 %** et validez. Lorsque l'utilisateur déposera une note de frais, seuls 80 % du montant de TVA indiqué sur le ticket seront récupérés.
