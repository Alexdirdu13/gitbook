# Comment afficher les données d'un groupe consolidé ?

## Afficher le groupe de manière dynamique

Sélectionner en haut à droite de votre écran le nom du consolidé que vous souhaitez afficher.

## Afficher le groupe de manière statique

Vous pouvez choisir d'afficher les données du groupe pour seulement l'une des colonnes de votre tableau en cliquant sur l'établissement dans l'en-tête.
