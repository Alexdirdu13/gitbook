# Comment éditer ou modifier une vue de votre compte de résultat ?

## Comment éditer ou modifier une vue de votre compte de résultat ?

Dans votre module Compte de résultat, vous avez la possibilité d'éditer ou modifier une vue de votre compte de résultat à tout moment. Ces modifications n'affectent jamais le compte d'un autre utilisateur. Seul un administrateur a la possibilité d'affecter le compte de ses collaborateurs en leur attribuant des vues par défauts.

## Modifier le nom d'une vue

Une fois en mode d'édition, vous avez la possibilité de changer le nom de la vue, pour cela, il vous suffit de cliquer sur le nom de la vue et d'insérer le texte désiré.

**Chemin : Valider les modifications**

## Valider les modifications

Une fois vos modifications réalisées, vous pouvez cliquer sur "**Valider les modifications**" afin de sortir du mode d'édition.

## Masquer ou supprimer des éléments de votre compte de résultat :

Pour chacun des éléments de votre compte de résultat, vous avez la possibilité de cliquer sur l'icône d'œil pour la ligne que vous souhaitez masquer, par exemple ici, la ligne chambres disponibles (ainsi que toutes ses sous-rubriques s'il y en a) ne sera pas visible en dehors du mode d'édition.

## Masquer ou supprimer des éléments de votre compte de résultat :

Vous avez également la possibilité de cliquer sur "**Réorganiser les comptes**" ce qui vous permet de d'ajouter (via l'icône de plus) de supprimer (via l'icône de corbeille) et de déplacer (en faisant glisser un élément) vos différents comptes.

## Mettre en forme votre rapport de gestion

Sur Qotid, vous avez la possibilité de mettre en couleur, en gras, en italique ou souligner des éléments de votre compte de résultat afin de les mettre en avant lors de sa consultation. Pour cela, il suffit de sélectionner une ou plusieurs lignes, puis dans le coin supérieur gauche, sélectionnez les options de mises en page désirées.
