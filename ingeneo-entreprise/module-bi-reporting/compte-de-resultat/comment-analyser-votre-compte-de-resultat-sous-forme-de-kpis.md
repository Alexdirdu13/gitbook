# Comment analyser votre compte de résultat sous forme de KPIs

## Comment analyser votre compte de résultat sous forme de KPIs

Pour afficher dans une ou plusieurs colonnes vos données sous forme d'indicateurs clés de performance (KPIs), il suffit de modifier les colonnes de votre rapport en cliquant sur Format de donnée et en sélectionnant Indicateur.

## Afficher les indicateurs

Ensuite en vous mettant directement sur la case sur la quelle vous voulez voir apparaitre votre indicateur vous cliquez dans la case et vous allez pouvoir choisir dans la liste déroulante votre indicateur.

## Sélectionner un indicateur

Enfin, pour chaque rubrique, vous pouvez sélectionner en fonction de quel indicateur vous souhaitez qu'elle soit affichée.
