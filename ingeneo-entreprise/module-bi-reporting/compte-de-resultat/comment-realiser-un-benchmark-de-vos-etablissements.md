# Comment réaliser un benchmark de vos établissements

## Comment réaliser un benchmark de vos établissements

Pour réaliser une vue avec plusieurs établissements sur un rapport unique dans votre Module Compte de Résultat, il suffit de modifier les colonnes de votre rapport en cliquant sur **Établissement par défaut** et en sélectionnant directement les hôtels à comparer dans chacune de vos colonnes.

## Exemple de benchmark

Vous pouvez par exemple, afficher individuellement chacun de vos établissements puis afficher un consolidé du groupe
