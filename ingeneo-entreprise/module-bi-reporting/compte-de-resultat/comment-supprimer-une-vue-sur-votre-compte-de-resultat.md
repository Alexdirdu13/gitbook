# Comment supprimer une vue sur votre compte de résultat ?

## Supprimer une vue

Pour supprimer une vue dans votre compte de résultat, vous devez tout d'abord vous positionner sur votre vue puis cliquer sur "**Plus d'actions**" représenté par "**...**"

Ensuite, vous devez cliquer sur "**Supprimer la vue**". Celle-ci sera alors définitivement effacée.

## Supprimer une vue par défaut

Si votre vue est définie en tant que vue par défaut, vous devez dans un premier supprimer la vue par défaut afin de pouvoir ensuite la supprimer définitivement en cliquant sur "**Plus d'actions**", puis "**Supprimer vue par défaut**".
