# Comment personnaliser le P\&L avec l'ajout de couleur

## Comment personnaliser le P\&L avec l'ajout de couleur

Dans votre module "**Compte de Résultat**", vous pouvez dorénavant utiliser la fonctionnalité personnalisation sur Qotid.

Pour cela, rendez-vous sur votre interface. Cliquez sur le crayon permettant d'éditer la vue, comme ci-dessous.

## Cocher les lignes souhaité

Ensuite, **cochez** la ligne que vous souhaitez personnaliser (vous pouvez en sélectionner plusieurs en une seule fois)

## Options de personnalisations

Une ligne avec plusieurs possibilités de personnalisation apparait, gras, italique, souligné, surligné, couleur de police, majuscule. Vous pouvez ici changer et personnaliser la ou les lignes que vous avez sélectionnées.

## Exemple de personnalisation

Vous pouvez ainsi personnaliser votre interface en changeant la couleur de votre police ou en ajoutant une couleur de surbrillance. Ainsi, vos écritures seront plus simples à lire et vous pourrez facilement prendre vos marques.

Par exemple : vous pouvez rendre la ligne des chambres disponibles verte avec le texte en gras et celle des chambres vendues jaune avec le texte en gras, ainsi, en un coup d'oeil vous pouvez les différencier.

## Valider les modifications

Une fois vos modifications apportées, vous n'avez plus qu'à quitter le mode édition pour **valider les modifications**, la sauvegarde est automatique.

**Chemin : Dupliquer une vue**

## Dupliquer une vue

Vous avez la possibilité de dupliquer une vue pour conserver la mise en forme d'un compte de résultat.

Dans le menu déroulant des vues, en face de la vue à dupliquer, cliquer sur les **...**

Puis **Dupliquer**

**Attention :**

Lorsque vous dupliquez une vue partagée, la nouvelle vue n'est pas partagée par défaut, elle est dupliquée dans "Mes visualisations"
