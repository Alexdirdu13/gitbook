# Comment sélectionner une période sur date personnalisée sur une vue de votre compte de résultat?

## Sélectionner "date personnalisée"

Il est possible de visualiser sur une plage de date personnalisée vos données à partir de votre compte de résultat. Pour cela rien de plus simple : Dans les boutons permettant la sélection de la plage de date, vous pouvez voir apparaître "**Date personnalisée**", il vous suffit de cliquer dessus.

## Définissez vos dates

Choisissez une date de début et une date de fin pour la visualisation de vos données. Cliquer sur valider pour voir l'ensemble de vos données sur une période au préalable choisie

Pour information, l'opération peut également se faire depuis vos rapports ou vos budgets
