# Comment utiliser le filtre avancé pour faire des analyses sur vos écritures comptables

## Comment utiliser le filtre avancé pour faire des analyses sur vos écritures comptables

Dans Qotid vous avez la possibilité d'analyser facilement les écritures comptables d'une rubrique spécifique de votre reporting en cliquant dessus. Cependant, il viendra éventuellement un moment où vous aurez besoin d'analyser de manière plus approfondie les écritures comptables issues de votre grand livre comptable. Pour cela, lorsque vous affichez le détail de vos écritures sur une rubrique de votre reporting, il suffit de cliquer sur "**Voir toutes les écritures comptables**".

## Filtrer vos écritures comptables

Un nouvel onglet va s'ouvrir, dans cet onglet vous pourrez paramétrer des filtres selon lesquels vous souhaitez visualiser vos écritures comptables :

* **Établissements** : sélectionner un ou plusieurs établissements selon vos accès
* **Date** : sélectionner les écritures comptables que vous souhaitez extraire selon leur date de saisie
* **Libellé** : vous pouvez effectuer une recherche selon le libellé comptable utilisé lors de la saisie de la facture selon une valeur exacte (Egale) ou selon une approximation (Contient).
* **Numéro de compte** : vous pouvez filtrer selon des numéros de comptes spécifiques
* **Rubrique associée** : vous pouvez afficher toutes les écritures comptables associées à une ou plusieurs rubriques de votre reporting
* **Débit** : pour une charge, vous pouvez faire une recherche selon un montant spécifique
* **Crédit** : pour un produit, vous pouvez faire une recherche selon un montant spécifique

## Valider les filtres

Une fois votre filtre valider, vous pouvez voir toutes les écritures comptables dans le tableau sur la droite, vous pouvez alors si vous le souhaitez, extraire le résultat au format CSV, pour cela, cliquez sur "**Export CSV**".
