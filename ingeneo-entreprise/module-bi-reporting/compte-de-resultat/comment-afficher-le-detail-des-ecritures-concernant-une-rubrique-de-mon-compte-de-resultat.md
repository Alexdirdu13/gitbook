# Comment afficher le détail des écritures concernant une rubrique de mon compte de résultat

## Comment afficher le détail des écritures concernant une rubrique de mon compte de résultat

Lorsque vous êtes sur le module **Compte de résultat**, vous pouvez afficher le détail des écritures comptables qui alimentent votre reporting. Pour cela, il suffit de sélectionner le montant pour lequel vous souhaitez obtenir des informations.

## Cliquer sur un élément

Par exemple je souhaite obtenir le détail des éléments qui alimentent les charges Electricité pour un montant de 8 568€.

## Visualiser les écritures comptables

Une fenêtre s'affiche alors avec le détail de toutes les écritures comptables sur la période sélectionnée. Pour effectuer des analyses approfondies des écritures de votre reporting, vous pouvez utiliser le filtre avancé pour faire des analyses sur vos écritures comptables.
