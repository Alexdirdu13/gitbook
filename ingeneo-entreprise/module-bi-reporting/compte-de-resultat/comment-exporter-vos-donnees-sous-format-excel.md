# Comment exporter vos données sous format Excel

## Comment exporter vos données sous format Excel

Pour exporter vos données au format Excel, il suffit de sélectionner "**Plus d'actions**"puis "**Export Excel**". Attention, vos données seront exportées telles que vous les voyez à l'écran, il est donc important de bien configurer votre vue avant de l'exporter

## Sélection des établissements

Une fenêtre va s'ouvrir sur la gauche, vous pouvez alors sélectionner pour quels établissements ou groupes vous souhaitez télécharger la vue.
