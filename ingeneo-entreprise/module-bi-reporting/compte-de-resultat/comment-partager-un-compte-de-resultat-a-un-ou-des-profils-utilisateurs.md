# Comment partager un compte de résultat à un ou des profils utilisateurs ?

## Comment partager un compte de résultat à un ou des profils utilisateurs ?

Pour commencer, il faut savoir que le partage d’une vue est uniquement possible pour les utilisateurs disposant d’un profil **Administrateur**.

Partager une vue de votre **compte de résultat** avec vos collaborateurs permet de leur donner accès à la **structure** et aux **données**, **sans** qu’ils puissent la **modifier** ou la **supprimer**.

Dans le menu déroulant des vues, vous trouverez 2 dossiers :

* **Visualisations partagées** : regroupe toutes les vues partagées par des administrateurs.
* **Mes visualisations** : regroupe les vues auxquelles **vous seul(e)** avez accès.

## Partager une vue

Dans le menu déroulant des vues, en face de la vue à partager, cliquer sur les **...**

Puis **Partager**

## Sélection des profils

Tous les profils utilisateurs s'affichent.

Sélectionner les profils désirés puis cliquez sur **Valider.**

La vue sera partagée à tous les utilisateurs rattachés à ce(s) profil(s) ainsi que ceux qui y seront ajoutés ultérieurement.

**À savoir :**

La partage des vues se fait automatiquement par défaut sur le profil **Administrateur**

**Chemin : Partager un dossier**

## Partager un dossier

Vous pouvez organiser vos vues par **dossiers**.

Si vous partagez une vue rattachée à un dossier, le profil utilisateur aura accès au **dossier** dans le menu des vues, ainsi qu’aux **vues partagées** qu’il contient — mais **uniquement** à celles qui lui ont été effectivement partagées (les autres vues du dossier resteront invisibles).

## Dupliquer une vue

Vous avez la possibilité de dupliquer une vue pour conserver la mise en forme d'un compte de résultat.

Dans le menu déroulant des vues, en face de la vue à dupliquer, cliquer sur les **...**

Puis **Dupliquer**

**Attention :**

Lorsque vous dupliquez une vue partagée, la nouvelle vue n'est pas partagée par défaut, elle est dupliquée dans "Mes visualisations"
