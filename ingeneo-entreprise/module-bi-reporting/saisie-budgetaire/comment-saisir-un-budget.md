# Comment saisir un budget ?

## Comment saisir un budget

Pour saisir un budget, allez sur le module **"Budgets"**

## Se positionner sur la bonne date

Avant de commencer à saisir sur un budget, il est important de se positionner sur la bonne date.

Pour cela, vous pouvez cliquer sur l'icône d'agenda ou directement cliquer sur la date afin de la modifier.

Il est important de se positionner sur la date de fin de période, par exemple, si vous souhaitez saisir votre budget 2024 alors, positionnez-vous à la date du 31 décembre 2024.

## Choisir le budget sur lequel vous souhaitez saisir de la donnée

Pour cela cliquez sur vos budgets en haut à gauche et sélectionnez le budget que vous voulez saisir\*\*.\*\*

**À savoir :**

Par défaut, les vues que vous allez créé auront 13 colonnes. Une pour chaque mois ainsi que l'année entière. Elle sera aussi paramétrée par défaut au budget depuis lequel vous l'avez créé pour la période.

## Sélectionner une donnée

Pour commencer à saisir une donnée, cliquez sur la donnée souhaitée comme ci-dessous.

**Chemin : Revenir aux différentes possibilités pour insérer de la donnée / Les différentes possibilités pour insérer de la donnée**

## Les différentes possibilités pour insérer de la donnée

Ici, vous avez quatre possibilités pour insérer de la donnée

**À savoir :**

En cliquant sur les boutons ci-dessous, nous vous expliquons l'utilité et les différences entre ces 4 choix

**Chemin : Montant fixe récurrent**

## Montant fixe récurrent

**À savoir :**

Ici vous pouvez saisir un montant fixe connu à l'avance pour votre prévisionnel

## Donner un nom au libellé

Vous devez indiquer un libellé pour chaque montant saisi

**À savoir :**

Par défaut le nom du libellé est le même que celui de votre rubrique

**Attention :**

Le nom d'un libellé doit être unique, sinon il ne sera pas ajouté

## Entrer une donnée

Vous pouvez ensuite entrer une donnée. Par exemple 250 pour votre nombre de clients bar

## Choix de la période

Vous pouvez automatiquement ajouter votre libellé (et donc votre montant fixe) sur une période prédéfinie.

Par exemple si vous sélectionnez "**Année en cours**" le libellé sera ajouté sur tout l'année.

## Appliquer une récurrence

Si vous avez choisi une période autre que mensuelle, vous pourrez appliquer une récurrence

Par exemple si vous avez choisi comme période "**Année en cours**" et que vous sélectionnez comme récurrence "**Tous les 2 mois**" le libellé sera inséré un mois sur deux sur l'année en cours (janvier 2024, mars 2024, mai 2024...)

## Ajouter le libellé sur plusieurs établissements

Vous pouvez également ajouter ce libellé sur plusieurs établissements, pour cela, cliquer sur "**Appliquer sur d'autres établissements**" et sélectionnez les établissements sur lesquels vous souhaitez afficher la donnée.

## Réserver la modification de ce libellé aux administrateurs

Enfin, si vous êtes administrateur du budget, vous pouvez choisir de réserver la modification de ce libellé aux administrateurs, ainsi, les utilisateurs non-administrateurs du budget ne pourront pas modifier ce libellé.

## Valider l'ajout

Pour finir et confirmez votre saisie, cliquez sur **"Valider"**.

## Visualiser la donnée

Dorénavant, si vous cliquez de nouveau sur votre donnée, votre ajout est visible comme ci-dessous.

## Modifier le libellé

Si vous souhaitez le modifier, cliquez sur le "**crayon**"**.**

## Editer la nouvelle donnée du libellé

Vous pouvez modifier les éléments suivants: -Le nom du libellé -Le montant/ la formule -La période -La récurrence -Vous pouvez appliquer la modification sur plusieurs établissements -Vous pouvez réserver la modification aux administrateurs

## Supprimer le libellé

Si vous souhaitez supprimer la saisie il suffit de cliquer sur la **corbeille**

## Paramètre de la suppression du libellé

Vous pouvez choisir la période sur laquelle vous souhaitez supprimer le libellé. Vous pouvez aussi le supprimer sur plusieurs établissements

## Changer la réservation de la modification aux administrateurs

Si le cadenas est ouvert, tous les utilisateurs qui peuvent saisir sur le budget peuvent modifier ce libellé. Si le cadenas est fermé, seul les administrateurs pourront modifier la donnée.

**À savoir :**

Pour ouvrir ou fermé le cadenas il suffit de cliquer dessus

## Ajouter un nouveau libellé

Si vous souhaitez ajouter un nouveau libellé vous pouvez réitérer les opérations indiquées dans ce guide sur la même rubrique.

En effet sur Qotid vous pouvez ajouter plusieurs libellé sur une rubrique précise sur les charges ou les revenus.

**À savoir :**

Par exemple si vous avez plusieurs fournisseurs en produit d'entretien vous pourrez avoir deux libellés FOURNISSEUR 1 et FOURNISSEUR 2

## Créez un calcul système

Un calcul système est une formule qui est attachée aux paramètres de votre budget.

**À savoir :**

Cette formule sera automatiquement appliquée sur tous vos établissements.

**Attention :**

Ces formules ne peuvent être créée ou modifiées que par les personnes qui ont un profil administrateur

## Saisir votre formule

Ici, vous devez saisir votre formule. Pour ajouter une catégorie appuyez sur "**Basé sur une catégorie**" Par exemple, ici, on saisit une formule indiquant que notre prix moyen HT est la division de notre CA hébergement HT par notre nombre de chambres vendues

Enfin appuyer sur "**Valider**"

## Visualiser la donnée

Dorénavant, si vous cliquez de nouveau sur votre donnée, votre ajout est visible comme ci-dessous.

**Attention :**

Attention on ne peut pas saisir de la donnée sur une catégorie contenant un calcul système

## Modifier le calcul système

Si vous souhaitez le modifier, cliquez sur le "**crayon**"**.**

## Editer le calcul système

Vous pouvez modifier la formule de votre calcul.

## Supprimer le calcul système

Si vous souhaitez supprimer le calcul, il suffit de cliquer sur la **corbeille**
