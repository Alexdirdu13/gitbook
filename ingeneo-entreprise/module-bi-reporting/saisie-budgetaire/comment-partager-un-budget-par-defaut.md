# Comment partager un budget par défaut

## Comment partager un budget avec vos collaborateurs ?

Tout d'abord, il est important de rappeler que seuls les administrateurs ont la possibilité de partager leurs budgets par défaut. Il est donc recommandé que les administrateurs soient à l'origine des budgets s'ils souhaitent pouvoir les partager. Nous allons vous expliquer dans cet article comment partager le budget avec vos collaborateurs qui grâce à cela pourront saisir sur le budget partagé :

Pour commencer cliquer sur "**Reporting**" puis "**Budgets**".

**Chemin : Étape suivante**

## Aller dans les paramètres budgets

Ensuite, cliquez sur "**Budgets**" et choisissez le budget que vous souhaitez partager parmi la liste de vos budgets\*\*.\*\*

## Partager le budget

Cliquez ensuite sur les "..." en haut de l'écran puis sur "Partager le budget"

## Sélectionner les profils

Puis cochez les profils avec qui vous souhaitez le partager et cliquez sur "**Valider**".

## Votre budget est validé

Si vous souhaitez que vos collaborateurs puissent saisir sur un budget par défaut vous devez leur donner les autorisations nécessaires. Il est également possible de partager les vues associées à un budget comme vous pourriez le faire sur le compte de résultat.
