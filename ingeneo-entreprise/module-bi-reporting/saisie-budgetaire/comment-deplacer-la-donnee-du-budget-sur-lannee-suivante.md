# Comment déplacer la donnée du budget sur l'année suivante

## Déplacer la donnée du budget

Une fois votre budget saisie, il est possible de déplacer les données renseignées sur l'année suivante.

Pour cela, sélectionnez votre budget, puis cliquez sur les "..." et enfin cliquez sur "Déplacer la donnée du budget".

## Déplacer la donnée

Sélectionnez "Déplacer la donnée de 12 mois", vous pouvez également choisir d'appliquer cette modification sur d'autres établissements.

Enfin cliquez sur "Valider"
