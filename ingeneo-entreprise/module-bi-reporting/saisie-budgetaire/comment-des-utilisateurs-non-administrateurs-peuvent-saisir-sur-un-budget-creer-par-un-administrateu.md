# Comment des utilisateurs non administrateurs peuvent saisir sur un budget créer par un administrateu

## Comment des utilisateurs non-administrateurs peuvent saisir sur un budget créé par un administrateur

Si vous souhaitez que vos collaborateurs puissent saisir sur un budget par défaut vous devez leur donner les autorisations nécessaires. Pour cela rendez-vous dans l'onglet "**Paramètre compte**" et de cliquer sur "**Collaborateurs**".

## Aller dans l'onglet profils

Cliquez sur "**Profils**" en haut à gauche. Choisissez le profil qui vous intéresse, puis cliquez sur **Editer**.

## Autoriser l'édition

Si vous souhaitez que les utilisateurs associés à ce profil puissent éditer le budget par défaut, il faut leur donner l'autorisation. Pour cela, cochez **Éditer budget par défaut** dans le module budget.

## Partager les budgets

Bien évidemment, vous devrez également vous assurez que les utilisateurs non-administrateurs ont également accès au budget par défaut sur lequel vous souhaitez qu'ils saisissent.

Vous pouvez leurs partager ces budgets ici ou via le module budget (ainsi que les vues par défaut qui leurs sont liés)
