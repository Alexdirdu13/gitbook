# Comment dupliquer un budget ?

## Comment dupliquer un budget

Pour dupliquer un budget, allez sur le module"**Budget**"**.**

## Aller dans les paramètres budget

Ensuite, selectionnez le budget que vous souhaitez partager en haut à gauche puis cliquez sur les "..." puis sur "Dupliquer le budget".

**Chemin : Paramétrage de la duplication**

## Paramétrage de la duplication

Deux choix s'offrent à vous :

**Chemin : Dupliquer avec les paramétres et les données**

## Dupliquer avec les paramétrages et les données

Vous pouvez **dupliquer le budget avec les paramètres et les données** : cela récupérera toutes les données saisies sur le budget en question. Cela peut s'avérer utile si vous souhaitez par exemple, saisir les budgets de 2025 à partir des données saisies en 2024. Vous pourrez ainsi dupliquer votre budget et saisir le nombre de mois pour décaler les données de la période correspondante. Dans notre exemple, vous souhaiterez décaler les données de 12 mois.

**Chemin : Valider votre choix**

## Valider votre choix

Valider votre choix en cliquant sur " Dupliquer ". Vous recevrez une notification par email lorsque la duplication sera terminée

## Retrouver votre budget

Le duplicata de votre budget apparait dorénavant dans votre liste.

**Chemin : Dupliquer avec les paramètres uniquement**

## Dupliquer avec les paramètres uniquement

Vous pouvez le dupliquer uniquement les paramètres : Aucune des données saisies ne sera dupliquée.
