# Comment importer les données depuis un budget vers un autre budget ?

## Comment importer les données depuis un budget

Dans cet article nous allons vous expliquer comment importer des données d'un budget vers un autre, cela peut être intéressant si par exemple vous souhaitez créer une nouvelle version de votre budget à partir d'un autre. Pour commencer, cliquez sur le module "**Budget**".

## Aller dans les paramètres budgets

Ensuite, Sélectionnez le budget sur lequel vous voulez importer de la donnée en haut à gauche , puis cliquez sur les "**...**" et enfin cliquez sur "Importer des données depuis un autre budget".

## Sélectionner le budget d'origine et la période

Ensuite, sélectionnez le budget à partir duquel vous voulez importer des données. Ici, Qotid vous propose automatiquement les budgets qui ont des caractéristiques identiques à celui sélectionné.

Sélectionnez également la période sur laquelle vous souhaitez importer les données. Vous pouvez la personnaliser et choisir une date de début et une date de fin, ou alors toute la période. Enfin, sélectionnez les établissements sur lesquels vous souhaitez importer les données.

## Valider la duplication

Enfin, cliquez sur "**Valider**".

Vos données sont importées !
