# Comment créer un budget ?

## Comment créer un budget sur Qotid

Vous voulez créer un budget ? Pour cela vous devez avoir le module budget activé sur votre espace en tant qu'administrateur. Ce module est activable par nos équipes si vous souhaitez souscrire au module budget. Si vous ne l'avez pas sur votre écran et que vous n'êtes pas un administrateur, renseignez-vous auprès de vos administrateurs et assurez-vous que vous avez les droits sur ce module.

Pour commencer cliquer sur "**Reporting**" puis "**Budgets**".

## Ajouter un budget

Ensuite, cliquez sur vos budgets en haut à gauche et sur "**Ajouter un budget**".
