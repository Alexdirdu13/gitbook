# Comment supprimer la donnée de mon budget

## Selectionnez votre budget

Selectionnez le budget concerné, puis cliquer sur les "..." en haut de l'écran.

Enfin, cliquez sur "Supprimer la donnée du budget"

## Selectionnez la période à supprimer

Vous pouvez ensuite choisir de supprimer toute la donnée ou supprimer les données sur une plage de date spécifiques.

Vous pouvez également appliquer cette action sur plusieurs établissements.

Cliquez enfin sur "Valider". **Attention, cette action est irréversible.**
