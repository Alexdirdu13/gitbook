# Ajouter dans paramètre P\&L un compte qui a été créé uniquement dans le budget

## Sélectionner le compte à dupliquer dans le P\&L

Aller dans votre module **Budget**, puis, appuyer sur le stylo à la droite du compte. (Les comptes créés uniquement dans le budget ont un stylo à leur droite).

## Dupliquer le compte dans paramètre P\&L

Sélectionner : "déplacer vers le P\&L".

## Attention à vos calculs dans "paramètre P\&L"

Vérifier que vos calculs restent cohérents dans paramètre P\&L avec l'ajout de ce nouveau compte.
