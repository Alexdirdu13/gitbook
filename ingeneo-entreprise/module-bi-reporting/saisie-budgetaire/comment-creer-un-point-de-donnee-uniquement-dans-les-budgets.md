# Comment créer un point de donnée uniquement dans les budgets ?

## Créer une nouvelle rubrique

Pour cela, vous devez vous rendre dans votre module budget et sélectionner le budget sur lequel vous voulez ajouter le nouveau compte. Puis appuyez sur "**...**" en haut à gauche avant de sélectionner "**Ajouter une nouvelle rubrique**".

**À savoir :**

Si votre budget a déjà été validé, vous ne pourrez pas ajouter un nouveau compte.

## Paramétrer le nouveau compte

Ensuite, vous devez paramétrer ce nouveau compte avant d'appuyer sur "**Valider**".

## Attention à vos calculs

Si vous créez un nouveau compte uniquement dans le budget, vous pourrez lui définir une donnée brut ou un calcul comme donnée comme n'importe quel autre compte dans votre budget.

Cependant, si vous lui créez des comptes enfants, alors, il sera forcement la somme de ses enfants.
