# Comment supprimer vos associations comptables ?

## Réaliser une association comptable

![Capture d'écran](../../.gitbook/assets/assoc-suppr-1.png)

![Capture d'écran](../../.gitbook/assets/assoc-suppr-2.png)

Lorsque vous accédez au Module Compte de résultat, vous avez la possibilité de supprimer les associations comptables de votre compte de résultat.

* Pour y accéder ; cliquer sur "**Plus d'actions**" depuis le compte de résultat puis sur "**Modifier les associations comptables**"..

**Attention :**

Attention cette action est définitive et vous devrez recommencer le paramétrage de vos écritures comptables.

## Glisser déposer vos numéros de comptes comptable

![Capture d'écran](../../.gitbook/assets/assoc-suppr-3.png)

![Capture d'écran](../../.gitbook/assets/assoc-suppr-4.png)

Vous pouvez ensuite cliquez sur **Déjà associés**.

## Supprimer les associations comptables

![Capture d'écran](../../.gitbook/assets/assoc-suppr-5.png)

![Capture d'écran](../../.gitbook/assets/assoc-suppr-6.png)

Vous retrouverez sur cette page l'ensemble de vos associations comptables.

Si vous souhaitez supprimer l'ensemble des associations, faites défiler vers le bas la fenêtre de droite et cliquez sur **Supprimer les associations**
