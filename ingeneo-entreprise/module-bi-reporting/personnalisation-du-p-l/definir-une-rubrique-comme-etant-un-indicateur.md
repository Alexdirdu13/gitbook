# Définir une rubrique comme étant un indicateur

## Définir une rubrique comme étant un indicateur

Activer une rubrique comme étant un KPI vous permettra de réaliser une vue avec vos données sous forme d'indicateurs clés de performance (KPIs) en colonne dans le P\&L ou bien dans vos dashboards.

Pour cela dans le paramétrage de votre reporting, il suffit de cocher la case Indicateur.
