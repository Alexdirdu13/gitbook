# 3. Comment se déroule la validation des processus par les utilisateurs ?

## Inroduction

Le processus de validation de vos tâches se déroule directement depuis votre module Compte de Résultat. La possibilité de valider vos données à un certain niveau dépend de l'organisation de votre groupe et est définie sur mesure par vos administrateurs. (lien vers guide sur [gérer le niveau de validation des utilisateurs](2.-comment-gerer-le-niveau-de-validation-de-vos-utilisateurs.md)) Si votre profil vous permet d'afficher la visualisation des validations, vous trouverez un cercle qui a différentes significations selon sa couleur.

## Pastille rouge

Vous pouvez valider le processus pour atteindre le niveau de validation affiché dans le cercle. _Exemple : dans l'image ci-contre, si vous validez le processus, vous atteindrez le niveau 1 de validation._

## Pastille orange

Vous ne pouvez pas valider le processus, mais vous êtes en attente de validation par un autre utilisateur afin de pouvoir à votre tour valider le processus. _Exemple : vous êtes un utilisateur avec un niveau de validation 2 et vous êtes dans l'attente qu'un utilisateur avec un niveau de validation 1 valide les données._

## Pastille verte

Le niveau de validation auquel vous êtes rattaché est validé.

## Comment valider le workflow

1/ Cliquer sur le cercle rouge.

2/ La date de validation est automatiquement affichée. Dans l'exemple ci-contre, l'établissement possède de la donnée à valider jusqu'au 30 Avril 2024.

3/ "Notifier les utilisateurs de niveau supérieur/inférieur". est sélectionné par défaut. Si vous ne désélectionnez cette case, les utilisateurs avec un niveau de validation et de lecture supérieur seront avertis par e-mail qu'ils doivent à leur tour valider les données. _NB : Les administrateurs ne seront pas notifiés._

4/ Le cas échéant vous pouvez également laisser un commentaire qui sera envoyé avec l'email de notification. Le commentaire est uniquement envoyé aux utilisateurs qui ont un niveau de validation supérieur. Les administrateurs et les utilisateurs avec un niveau de lecture supérieur ne recevront pas le commentaire.

## Comment valider le workflow des budgets

1/ Cliquer sur "**Validation budgétaire**".

2/ Sélectionner votre budget.

3/ La logique de validation est la même que pour le module compte de résultat pour le reste. Cependant, il n'y a qu'un seul niveau de validation pour le budget.
