# 1. Introduction Module Workflow

## Présentation

Le Module Workflow est un module de validation des données et de gestion de vos processus de validation en interne. Il vous permet de mettre en place une séquence de validation effectuée par une personne ou un groupe de personnes.

**Attention :**

_Attention : Ce module est activé sur option. Pour cela, veuillez contacter votre chargé de compte Qotid_
