# Comment ajouter un commentaire sur une rubrique de mon compte de résultat ?

## Ajouter un commentaire

Lorsque vous êtes sur le module "**Compte de résultat**" vous pouvez écrire des commentaires sur les rubriques de votre reporting. Pour cela, il suffit de cliquer sur le montant que vous souhaitez commenter.

**À savoir :**

Pour lire ou écrire des commentaires, il vous faut avoir les autorisations gérées par votre administrateur.

## Saisir le commentaire

Une fenêtre s'ouvre et vous pourrez saisir votre commentaire puis cliquer sur "**Ajouter**".

## Modification du commentaire

Le commentaire sera ensuite visible dans la fenêtre. Vous avez 30 jours pour modifier ou supprimer votre commentaire. Après cela, celui-ci ne sera plus modifiable.

## Visibilité du commentaire sur le P\&L

Lorsque vous commentez une donnée, la donnée est ensuite directement **soulignée** dans votre reporting. Si vous cliquez dessus vous pourrez visualiser à nouveau le commentaire. Toutes les personnes qui ont accès à votre établissement et qui ont les autorisations pour lire les commentaires pourront lire votre commentaire
