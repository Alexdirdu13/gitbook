# 2. Comment créer un nouveau tableau de bord ?

## Comment créer un nouveau tableau de bord ?

Si votre administrateur vous a donné les autorisations nécessaires, vous pouvez créer de nouveaux tableaux de bord sur Qotid. Ces rapports peuvent contenir plusieurs graphiques.

Ils ne seront visibles que par l'utilisateur qui les crée sauf si vous décidez de les partager ou de les définir par défaut.

Pour créer un rapport, sélectionner l’onglet **Tableaux de bord**. Une fois sur la page, en haut à gauche, vous pouvez cliquer sur le nom de votre rapport afin de faire apparaître la liste des rapports auxquels vous avez accès, en bas de cette liste, vous pouvez cliquer sur "**Créer un tableau de bord**".
