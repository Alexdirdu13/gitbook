# 4. Comment personnaliser vos graphiques de type tableaux ?

## Comment personnaliser vos graphiques de type tableaux

Sous l'onglet "**Tableaux de bord**", sélectionner un de vos graphiques de type tableau:

* **Ajouter une colonne** via l'icône de "+" cela peut vous permettre de comparer deux éléments dans un même graphique.
* **Retirer une colonne** via l'icône de croix.
* **Masquer une ligne** via l'icône d'œil.
* **Déplacer les colonnes** via les 3 lignes.

## Paramétrage des colonnes

Vous avez la possibilité de paramétrer individuellement chacune des colonnes de votre graphique, en laissant le paramétrage par défaut, le paramétrage se fera en fonction de ce que vous avez entré dans les différents champs à gauche sous "Edition du graphique".

Sinon, vous pouvez forcer des comptes ou des établissements différents, cela peut vous permettre de comparer simplement deux éléments dans votre graphique.
