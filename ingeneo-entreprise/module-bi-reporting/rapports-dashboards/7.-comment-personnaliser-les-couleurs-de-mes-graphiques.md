# 7. Comment personnaliser les couleurs de mes graphiques ?

## Introduction

Les couleurs sur votre graphique ne vous conviennent pas ? Il est désormais possible de les personnaliser. Pour se faire, c'est simple ! Vous devez suivre ces étapes.

## Personnaliser les couleurs des garphiques

* Dans un premier temps cliquez sur le "**crayon**" en haut à droite de votre graphique.
* Cliquez sur "**Couleurs du graphique**".
* Sélectionnez les données dont vous souhaitez modifier la couleur.
* En cliquant sur les petits carrés de couleurs vous avez accès aux différents panels de couleurs afin d'effectuer vos modifications.

Voilà votre graphique est maintenant personnalisé !
