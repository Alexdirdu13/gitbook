# 9. Comment personnaliser les légendes de vos graphiques de type tableau ?

## Personnaliser les légendes de vos graphiques de type tableau

Pour personnaliser les légendes de vos graphiques, vous devez cliquez sur le "**crayon**" pour éditer e graphique

Vous trouvez des symboles en forme d'œil pour masquer les lignes :

**Période** --> si vous masquez la période (N, N-1, etc.) n'apparaîtra plus lorsque vous repasserez en mode graphique.

**Rubrique** --> si vous masquez le libellé de la rubrique, elle n'apparaîtra plus lorsque vous repasserez en mode graphique.

**Établissement** --> si vous masquez le nom de l'établissement, il n'apparaîtra plus lorsque vous repasserez en mode graphique.

**Intervalle** --> si vous masquez l'intervalle, il n'apparaîtra plus lorsque vous repasserez en mode graphique.
