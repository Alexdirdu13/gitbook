# Comment créer une facture (lorsqu’il n’y a pas eu de devis) ?

## Créer une facture

Si vous n'avez pas établi de devis et que vous souhaitez directement établir une facture, vous pouvez vous rendre dans l'onglet Ventes / Factures, puis cliquer sur le bouton **Créer une facture**.

## Informations générales

Une fenêtre s'ouvre vous permettant de paramétrer votre facture.

Vous pouvez saisir les informations générales :

1. Sélectionnez le client : une liste déroulante vous permet de choisir un client existant, s'il s'agit d'un nouveau client vous pouvez cliquer sur **Créer**.
2. Sélectionnez le mode de paiement parmi la liste déroulante.
3. Renseignez la date d'émission du devis et le délai de signature (le champ "à signer avant le" se calcule de manière automatique)

## Liste des articles

Vous pouvez ensuite renseigner les éléments suivants :

1- Préciser un objet

2- Renseigner un titre à la section

3- Sélectionner un produit parmi votre catalogue de produits, s'il n'existe pas encore vous pouvez cliquer sur le bouton **Créer**

4- Renseigner la quantité

5- Renseigner une remise (en % ou en €) le cas échéant

Vous pouvez ajouter autant de produits que vous le souhaitez à la section en cliquant sur le bouton "**Ajouter une ligne**".

Vous pouvez également créer une nouvelle section en cliquant sur le bouton "**Ajouter une section**".

## Pied de page

Vous pouvez ensuite renseigner les éléments du pied de page :

1- Afficher une mention spéciale.

2- Afficher les conditions générales de ventes

3- Afficher une note de pied de page

4 - Ajouter une annexe (fichier importé au préalable via l'écran Ventes / Paramètres / Annexes)

La facture contiendra par défaut les éléments que vous avez paramétrés au préalable dans l'onglet Ventes / Paramètres / Facture mais vous pouvez également personnaliser le contenu de chaque section directement sur la facture.

## Enregistrer et prévisualiser

Une fois terminé, vous pouvez cliquer sur le bouton **Enregistrer et prévisualiser** en bas à droite.
