# Comment établir un avoir ?

## Créer un avoir

Vous pouvez établir un avoir de deux manières différentes :

* À partir d'une facture créée sur Qotid ;
* Sans passer par une facture.

**Chemin : Créer un avoir à partir d'une facture**

## Créer un avoir à partir d'une facture

Pour créer un avoir à partir d'une facture émise sur Qotid, il suffit de se rendre dans l'onglet Ventes / Factures, puis de cliquer sur la facture pour la visualiser.

Cliquez ensuite sur les "...", puis sur le bouton **Créer un avoir pour cette facture**.

## Paramétrer l'avoir

Par défaut, l'avoir reprend les mêmes informations que la facture.

Mais vous pouvez le modifier en supprimant un produit, un prix, une remise, etc.

Une fois l'avoir terminé, vous pouvez cliquer sur le bouton **Enregistrer et prévisualiser** en bas à droite.

## Envoyer l'avoir

Votre avoir est au statut brouillon : vous pouvez l'envoyer pour le valider en cliquant sur le bouton **Envoyer l'avoir**.

**Chemin : Sans passer par une facture**

## Sans passer par une facture

Vous pouvez vous rendre dans l'onglet Ventes / Factures, puis cliquer sur le bouton **Créer un avoir**.

**Attention :**

N'hésitez pas à vérifier au préalable votre paramétrage concernant les avoirs (notamment la numérotation) dans la partie **Ventes > Paramètres > Avoirs**.

## Paramétrer l'avoir

Vous pourrez paramétrer votre avoir en spécifiant les champs suivants :

1. Le client
2. La date d'émission
3. L'objet
4. Les articles concernés

Une fois l'avoir paramétré, vous pouvez cliquer sur le bouton **Enregistrer et prévisualiser** en bas à droite.
