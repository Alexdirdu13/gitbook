# Comment créer un devis ?

## Créer un devis

Pour créer un devis, vous pouvez vous rendre sur le module **Ventes** puis cliquez sur **"Devis"**.

Cliquez ensuite sur le bouton **Créer un devis**.

## Informations générales

Une fenêtre s'ouvre vous permettant de paramétrer votre devis.

Vous pouvez saisir les informations générales :

1. Sélectionnez le client : une liste déroulante vous permet de choisir un client existant. Si le client recherché n'existe pas encore, vous pouvez cliquer sur **Créer**.
2. Sélectionnez le(s) mode(s) de paiement souhaités parmi la liste déroulante.
3. Renseignez la date d'émission du devis (par défaut à la date du jour) et le délai de signature (_le champ "à signer avant le" se calcule ensuite de manière automatique_)

## Liste des articles

Vous pouvez ensuite renseigner les éléments suivants :

1- Préciser l'objet de votre devis

2- Renseigner un titre à la section

3- Sélectionner un produit parmi votre catalogue de produits. S'il n'existe pas encore vous pouvez cliquer sur le bouton **Créer**

4- Renseigner la quantité

5- Renseigner une remise (en % ou en €) le cas échéant

Vous pouvez ajouter autant de produits que vous le souhaitez à la section en cliquant sur le bouton "**Ajouter une ligne**".

Vous pouvez également créer une nouvelle section en cliquant sur le bouton "**Ajouter une section**".

**Attention :**

Vous devez toujours sélectionner un produit existant (ou le créer s'il n'existe pas). Une fois sélectionné, vous pouvez toutefois modifier les informations du produit pour l'adapter à votre devis. Cela ne modifiera pas les informations par défaut du produit.

## Pied de page

Vous pouvez ensuite renseigner les éléments du pied de page :

1- Afficher une mention spéciale

2- Afficher les conditions générales de ventes

3- Afficher une note de pied de page

4 - Ajouter une annexe (fichier importé au préalable via l'écran Ventes / Paramètres / Annexes)

**Attention :**

Le devis contiendra par défaut les éléments que vous avez paramétrés au préalable dans l'onglet Ventes / Paramètres / Devis, mais vous pouvez également personnaliser le contenu de chaque section directement sur le devis.

## Enregistrer et prévisualiser

Une fois terminé, vous pouvez cliquer sur le bouton **Enregistrer et prévisualiser** en bas à droite.
