# Comment importer une facture client qui n’a pas été créée sur Qotid ?

## Importer une facture

Vous pouvez importer les factures de ventes que vous avez émises depuis un autre logiciel de facturation.

Pour cela, il existe deux méthodes :

**Chemin : Importer une facture manuellement**

## Importer une facture manuellement

Pour importer une facture manuellement, vous pouvez vous rendre sur l'onglet Ventes / Factures puis cliquez sur le bouton **Importer une facture via OCR.**

Il vous suffit de sélectionner le (ou les) PDF sur votre PC et cliquer sur Ouvrir.

**Chemin : Importer une facture via l'adresse mail Qotid**

## Importer une facture via l'adresse mail Qotid

Vous pouvez consulter vos adresses mails Qotid personnalisées en cliquant sur la molette en haut à gauche.

Puis cliquez sur le bouton **Adresses emails**.

Il y a deux adresses mails par établissement :

* une pour les factures d'achat (fournisseurs)
* une pour les factures de vente (clients)

Il vous suffira ensuite d'envoyer votre facture directement sur l'adresse mail de vente, elle sera alors automatiquement intégrée (et lue par l'OCR) sur votre espace Qotid.

**Attention :**

Vous pouvez également consulter l'historique des mails envoyés sur vos adresses mail Qotid en cliquant sur la molette puis sur **Emails reçus**.
