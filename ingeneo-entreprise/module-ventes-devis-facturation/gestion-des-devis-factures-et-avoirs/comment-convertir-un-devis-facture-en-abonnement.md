# Comment convertir un devis / facture en abonnement ?

## Convertir un devis / une facture

Lorsque votre devis est envoyé ou accepté (ou lorsque votre facture est émise), vous pouvez convertir ce document en abonnement.

Pour cela, vous pouvez vous rendre sur le document et cliquer sur les "..." en haut, puis sur **Transformer en abonnement**.

## Créer un abonnement

Vous aurez alors 2 options :

1. Utiliser un modèle d'abonnement déjà existant
2. Créer un modèle à partir du document

Vous pouvez vous référer aux guides ci-dessous en fonction de l'option choisie.

**Chemin : Utiliser un modèle existant**

## Utiliser un modèle existant

Renseignez les informations suivantes :

1. Sélectionnez le modèle d'abonnement que vous avez créé au préalable.
2. Sélectionnez le client qui a souscrit à l'abonnement (vous pouvez également le créer s'il n'existe pas encore dans Qotid). Vous pouvez également sélectionner le contact à qui seront adressées les factures.
3. Renseignez les dates de début et de fin d'abonnement.
4. Renseignez la fréquence de facturation. Vous pouvez également visualiser l'échéancier généré automatiquement.
5. Vous pouvez spécifier le statut de chaque facture qui sera générée. Pour que la facture soit validée et envoyée directement sans action de votre part, sélectionnez "Une facture finalisée et son envoi par e-mail".
6. Enfin, sélectionnez la rubrique de trésorerie dans laquelle vous souhaitez l'enregistrer.

**Chemin : Créer un modèle à partir du document**

## Créer un modèle à partir du document

S'agissant d'un modèle, aucune information de client n'est affichée.

Renseignez ensuite les différentes informations que vous souhaitez voir affichées sur les factures générées :

1. L'objet de la facture
2. Le mode et le délai de paiement
3. Les articles de votre catalogue de produits
4. Les informations du pied de page

Cliquez ensuite sur **Suivant**.
