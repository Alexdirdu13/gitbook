# Comment indiquer mon devis comme accepté ou refusé ?

## Visualiser votre devis

Pour consulter votre devis, vous pouvez vous rendre dans l'onglet Ventes / Devis puis sélectionner la rubrique **Envoyé**.

Cliquez ensuite sur votre devis pour le visualiser.

## Accepter ou refuser un devis

Une fois votre devis ouvert, vous pouvez soit :

* Accepter le devis en cliquant sur le bouton **Devis accepté**
* Refuser le devis en cliquant sur les "**...**" en haut puis cliquer sur le bouton **Marquer comme refusé**.
