# Comment exporter la liste des clients

## Sélectionner les clients à exporter

* Sélectionner l'onglet "Contact"
* Puis sélectionner "Clients"
* A l'aide de la colonne de sélection, sélectionner les clients souhaités

**Chemin : Suivant**

## Cliquer sur Export Excel

* Après avoir sélectionner les clients, le bouton "Export Excel" apparait
* Cliquer sur "Export Excel"

**Chemin : Suivant**

## Téléchargement de l'export

* Après le clic sur "Export Excel", le fichier apparait dans les téléchargements
*   Le fichier comporte 3 onglets :

    Clients : Liste complète des entités sélectionnées avec leurs informations IBAN : Liste de tous les IBAN liés aux clients sélectionnés Contacts : Tous les contacts associés (nom, e-mail, téléphone…)
