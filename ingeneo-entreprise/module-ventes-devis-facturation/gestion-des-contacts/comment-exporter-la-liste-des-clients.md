# Comment exporter la liste des clients

## Sélectionner les clients à exporter

* Sélectionnez l'onglet "Contact"
* Puis sélectionnez "Clients"
* À l'aide de la colonne de sélection, sélectionnez les clients souhaités

**Chemin : Suivant**

## Cliquer sur Export Excel

* Après avoir sélectionné les clients, le bouton "Export Excel" apparaît
* Cliquez sur "Export Excel"

**Chemin : Suivant**

## Téléchargement de l'export

* Après le clic sur "Export Excel", le fichier apparaît dans les téléchargements
* Le fichier comporte 3 onglets :
  * Clients : liste complète des entités sélectionnées avec leurs informations
  * IBAN : liste de tous les IBAN liés aux clients sélectionnés
  * Contacts : tous les contacts associés (nom, e-mail, téléphone…)
