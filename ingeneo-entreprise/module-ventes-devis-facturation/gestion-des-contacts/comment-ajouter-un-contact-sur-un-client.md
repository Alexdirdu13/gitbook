# Comment ajouter un contact sur un client

## Afficher la liste des contacts

Pour avoir accès aux contacts de votre société, vous devez :

1. Sélectionner le module "Contacts"
2. Puis sélectionner l'onglet "Contacts"
3. Enfin, cliquer sur le bouton **Ajouter un contact**

## Ajouter un contact

1. Renseignez ensuite les informations principales du contact (les champs requis au minimum sont le nom et le prénom).
2. Vous pouvez ensuite lier votre contact à une (ou plusieurs) société(s) cliente(s). Pour cela, cliquez sur le bouton **Lier un client**.

## Lier un client

1. Sélectionnez la société concernée dans la liste déroulante.
2. Sélectionnez le type de contact parmi les propositions suivantes :
   * Principal
   * Facturation
   * Relance
   * Autre
   * Décisionnaire

Une fois paramétré, cliquez sur le bouton **Valider**.
