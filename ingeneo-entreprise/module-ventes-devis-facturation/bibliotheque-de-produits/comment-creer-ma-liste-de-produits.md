# Comment créer ma liste de produits ?

## Consulter la liste de produits

Pour créer votre liste de produits, vous pouvez vous rendre dans le module Ventes / Produits.

Vous pouvez visualiser l'ensemble des produits existants.

Pour ajouter un produit, cliquez sur le bouton **Ajouter un produit** en haut à droite.

## Ajouter un produit

Renseignez ensuite les caractéristiques de votre produit :

1. Le nom
2. L'unité (sélectionnez un élément parmi la liste déroulante)
3. La référence (facultatif)
4. La description du produit (facultatif)
5. Le prix HT
6. Le taux de TVA applicable
7. Le prix TTC se calcule automatiquement
8. Le type de produit (s'il s'agit d'une vente de marchandise, d'un service ou de frais)
9. Le n° de compte comptable de produit (l'attribution est automatique en fonction du type de produit sélectionné)

Une fois terminé, cliquez sur le bouton **Ajouter**.
