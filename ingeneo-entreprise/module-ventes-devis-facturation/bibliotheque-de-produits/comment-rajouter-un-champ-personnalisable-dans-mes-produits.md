# Comment rajouter un champ personnalisable dans mes produits ?

## Consulter les champs produit

Vous pouvez visualiser les champs produit en allant dans le module Ventes / Produits puis en cliquant sur l'onglet Champs produit.

Cliquez ensuite sur le bouton **Ajouter un champ.**

## Ajouter un champ

Renseignez les paramètres de votre champ personnalisé en indiquant :

1. Le nom du champ
2. S'il s'agit d'un champ obligatoire ou non
3. Le type (Texte libre, ou liste déroulante)

Cliquez ensuite sur le bouton **Enregistrer**.

## Champ disponible sur le produit

Lorsque vous ajouterez un produit à votre liste, ce champ sera désormais à renseigner.
