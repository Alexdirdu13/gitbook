# Comment exporter mes écritures comptables liées aux factures de ventes ?

## Export des écritures comptables

Une fois vos factures traitées sur Qotid, vous pouvez vous rendre dans l'onglet Comptabilité / Export comptabilité Client.

Vous verrez à l'écran les écritures comptables générées automatiquement, vous pouvez cliquer sur le bouton **Télécharger**.

Vous aurez le choix de télécharger les écritures avec les documents PDF ou sans les documents.

**Attention :**

Si vous ne voyez pas l'écran **Export comptabilité client**, cela signifie que cette option n'est pas comprise dans votre abonnement. N'hésitez pas à nous contacter pour en savoir plus.
