# Comment exporter mes documents de ventes pour la comptabilité ?

## Export des documents

Une fois vos factures de ventes générées sur Qotid, vous pouvez vous rendre dans l'onglet Comptabilité / Export document clients.

Vous pouvez sélectionner toutes les factures à transmettre à votre comptable puis cliquer sur le bouton **Télécharger**.

Vous obtiendrez un fichier Zip contenant l'ensemble des PDF de vos factures et avoirs sélectionnés.

## Documents déjà transmis

Dès que vous cliquez sur le bouton **Télécharger**, vos factures/avoirs passent automatiquement dans l'onglet "Déjà transmis" pour vous permettre d'avoir un suivi de ce que vous avez transmis ou non à votre comptable.
