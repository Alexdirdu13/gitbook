# Comment éditer un client ?

## Trouver la liste des clients

Cliquez sur le bouton "**Contact**" dans le menu principal à gauche de la page.

Puis, cliquez sur "**Clients**" pour accéder à la liste des clients.

## Editer un client

Pour éditer un client, passez votre souris sur le client et :

* Cliquez sur le bouton "**Crayon**" à droite afin de modifier / mettre à jour les informations de votre client.
* Cliquez sur le bouton "**Poubelle**" à droite afin de supprimer votre client.
