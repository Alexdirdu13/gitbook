# Comment configurer sa fiche client

## Se rendre sur la liste des clients

Il vous est possible, si vous en avez les droits de configurer votre fiche client en ajouter des champs. Pour se faire, il vous faut vous rendre dans votre liste fournisseur en cliquant sur "**Contacts**", puis "**Clients**". Cliquez ensuite sur l'onglet "**Champs client**".

## Configurer la fiche client

Pour ajouter un champ à la fiche client, cliquez sur "**Ajouter**" puis remplissez le libellé, si c'est un champ obligatoire, ainsi que le type de champ.
