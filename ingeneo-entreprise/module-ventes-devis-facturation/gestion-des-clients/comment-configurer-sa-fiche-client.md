# Comment configurer sa fiche client

## Se rendre sur la liste des clients

Si vous en avez les droits, il vous est possible de configurer votre fiche client en y ajoutant des champs. Pour ce faire, rendez-vous dans votre liste de clients en cliquant sur "**Contacts**", puis "**Clients**". Cliquez ensuite sur l'onglet "**Champs client**".

## Configurer la fiche client

Pour ajouter un champ à la fiche client, cliquez sur "**Ajouter**", puis renseignez le libellé, indiquez si c'est un champ obligatoire, ainsi que le type de champ.
