# Comment ajouter un client depuis une facture ?

## Ajouter un nouveau client depuis une facture

Cliquez sur le bouton "**Ventes**" dans le menu principal à gauche de la page.

Ensuite, cliquez sur "**Vue principale**", puis sur le bouton en forme d'"**œil**" à droite.

**Attention :**

Ce module n'est disponible que s'il est activé sur votre espace.

## Saisie du client

Une nouvelle fenêtre s'ouvrira : cliquez sur le bouton "**Client**".

* Dans la barre de recherche, écrivez le nom du client que vous souhaitez ajouter (**ex : Client 1**).
* Un bouton pour créer le client s'affichera : cliquez dessus et remplissez les informations de votre nouveau client.

## Validation du client

Cliquez sur le bouton "**Ajouter**" en bas à droite afin de valider votre demande de création d'un nouveau client.

## Trouver le client créé

Votre client est créé. Vous pouvez le trouver en saisissant son nom dans la barre de recherche.
