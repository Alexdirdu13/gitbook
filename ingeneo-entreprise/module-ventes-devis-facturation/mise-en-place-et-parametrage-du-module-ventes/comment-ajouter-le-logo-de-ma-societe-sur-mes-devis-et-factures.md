# Comment ajouter le logo de ma société sur mes devis et factures ?

## Logo

Pour ajouter le logo de votre société sur vos documents de ventes, vous pouvez vous rendre dans le module Ventes/Paramètres puis cliquer sur l'onglet Logo.

Cliquez ensuite sur le bouton **Ajouter un logo**.

**Attention :**

Les contraintes sur l'image à télécharger sont les suivantes :

Taille d'image recommandée :150 x 150 pixels @ 72 DPI

Taille maximale du fichier : 1MB
