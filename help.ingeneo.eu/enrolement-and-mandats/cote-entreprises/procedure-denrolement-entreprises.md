# Procédure d'enrôlement - Entreprises

Depuis Ingeneo, cliquez sur le menu **Paramètres** puis **Enrôlement PA**. Vous pouvez également y accéder depuis le menu **"Mandat et enrôlement Plateforme Agréee (PA)** disponible sur la barre d'en-tête.&#x20;

Identifier l'entreprise concernée, puis cliquez sur le bouton d'action pour lancer l'enrôlement.&#x20;

<div align="left" data-with-frame="true"><figure><img src="../../.gitbook/assets/image (79).png" alt="" width="456"><figcaption></figcaption></figure></div>

{% hint style="info" %}
**Avant de lancer un enrôlement**

* La session d'enrôlement expire au bout d'1 heure.
* L'enrôlement doit être réalisé par le représentant légal, muni d'un KBIS et d'une pièce d'identité (CNI).
* Les adresses électroniques à enregistrer sur l'annuaire doivent être renseignés lors de l'enrôlement.
* En cas de société détenue par une autre société, les KBIS de toute la chaîne sont nécessaires jusqu'au représentant légal personne physique.

[Voir guide de démarrage](guide-de-demarrage.md)
{% endhint %}

{% stepper %}
{% step %}
### **Dépôt du KBIS** et vérification des informations

L'entreprise téléverse le KBIS de la société. Les informations légales sont automatiquement extraites et&#x20;préremplissent le formulaire :\
• Raison sociale\
• Numéro de TVA intracommunautaire\
• SIREN\
• Adresse, code postal, ville

{% hint style="info" %}
Le champ SIREN est généralement grisé (non modifiable) car directement extrait du KBIS.\
Il est recommandé de vérifier l'exactitude des champs préremplis avant de passer à l'étape suivante,&#x20;notamment l'adresse postale.
{% endhint %}
{% endstep %}

{% step %}
### Sélection du représentant et vérification d'identité

Cette étape permet de désigner le représentant légal qui portera la démarche et signera l'accord. Les&#x20;champs à renseigner sont :\
• Prénom et nom\
• Fonction (ex. : Directeur Général, Président, etc.)\
• Numéro de téléphone mobile — utilisé pour la double authentification lors de la signature\
électronique via Yousign\
• Adresse email<br>

Une vérification d'identité est ensuite requise par upload d'une CNI ou d'un Passeport en cours de&#x20;validité. Un message de confirmation s'affiche une fois l'identité validée.

{% hint style="warning" %}
Le numéro de téléphone doit être joignable par SMS au moment de la signature ; toute erreur de saisie&#x20;bloquera l'étape 4.
{% endhint %}
{% endstep %}

{% step %}
### Régime de TVA et maillage des adresses de facturation

Cette étape définit comment l'entreprise apparaîtra dans l'Annuaire PPF et quelles adresses électroniques&#x20;recevront les factures.

**Régime de TVA**

• Fréquence de déclaration (ex. : déclaration mensuelle)\
• Exigibilité de la TVA (ex. : TVA sur les débits)

**Maillage d'adressage**

Le maillage permet de définir la ou les adresses électroniques de réception qui seront enregistrées sur&#x20;l'annuaire (ex : maille au niveau SIREN pour une réception centralisée, ou mailles par établissement).\
• Type de maille (SIREN, établissement, etc.)\
• Numéro SIREN concerné\
• Date d'effet et, le cas échéant, date de fin\
• Possibilité d'ajouter plusieurs mailles via le bouton « Ajouter une maille »
{% endstep %}

{% step %}
### Signature de l'accord via Yousign

La dernière étape consiste à signer électroniquement l'accord de désignation. Un code de vérification est&#x20;envoyé par SMS au numéro renseigné à l'étape 2, garantissant l'authenticité de la signature.\
• Cliquer sur « Lancer la signature »\
• Saisir le code reçu par SMS\
• Confirmer la signature électronique de l'accord
{% endstep %}

{% step %}
### Génération du document d'accord

À l'issue de la signature, un « accord formel de désignation de la plateforme de réception des factures et&#x20;de demande de mise à jour des adresses de facturation électronique de réception de factures » est&#x20;généré automatiquement. Il reprend l'ensemble des informations saisies durant le parcours.
{% endstep %}
{% endstepper %}
