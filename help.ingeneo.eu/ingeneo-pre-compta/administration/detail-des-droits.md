## Notes

* Dans INGENEO PRECOMPTA, un utilisateur a un seul profil d'administration, et un profil de site par site. Le profil d'administration ne contient aucun droit sur les classeurs.
* Dans INGENEO PRECOMPTA, un profil d'entreprise donne des droits sur une seule entreprise. Il l'emporte sur le profil de site. \[À VÉRIFIER : le profil d'entreprise contient-il les mêmes droits que le profil de site ?]
* Dans l'étape `Droits sur les classeurs` d'un profil de site d'INGENEO PRECOMPTA, l'interrupteur `Cocher tous les droits` active tous les droits de l'onglet affiché.
* Dans INGENEO PRECOMPTA, valider ou refuser un document ne demande aucun droit de profil. L'utilisateur doit avoir le rôle `Valideur` dans le circuit de validation.
* Dans INGENEO PRECOMPTA, un utilisateur déjà connecté reçoit ses nouveaux droits après s'être déconnecté puis reconnecté, ou après avoir rechargé la page.
* Les libellés des droits du profil d'administration et du profil de site finissent par un point dans INGENEO PRECOMPTA. Les libellés des droits sur les classeurs n'en ont pas. Libellés relevés dans la version 2.19.2.
