# Septembre - 2026

## Version 2.9.8 – 2026-09-28

### <i class="fa-sparkles">:sparkles:</i>Nouveautés

* **Traçabilité sur le document** (Réf. 2197) : nouveauté dans INGENEO PRECOMPTA.

### <i class="fa-wrench">:wrench:</i>Corrections

* **Fichier d'export avec la mauvaise heure (pour mandats et enrôlement)** (Réf. 7117) : dans INGENEO PRECOMPTA, le fichier d'export des mandats et des enrôlements n'affiche plus une heure erronée.
* **Enrôlement : blocage de la période de dates (fin au 31/12/2099)** (Réf. 7203) : correction dans INGENEO PRECOMPTA.
* **Traçabilité au niveau initiateur - Circuit de validation** (Réf. 5410) : correction dans INGENEO PRECOMPTA.
* **Réception de notifications d'initiation non souhaitées** (Réf. 6408) : dans INGENEO PRECOMPTA, les notifications d'initiation non souhaitées ne sont plus reçues.
* **Optimisations modification de documents (modification logo suppression, affichage des boutons `éclater...`)** (Réf. 2611) : correction dans INGENEO PRECOMPTA.
* **Découpage manuel des documents : avoir un zoom plus important sur l'affichage des pages** (Réf. 4963) : dans INGENEO PRECOMPTA, le découpage manuel des documents offre un zoom plus important sur l'affichage des pages.
* **Autres documents - format d'origine non disponible/respecté** (Réf. 6396) : correction dans INGENEO PRECOMPTA.
* **Bug de fusion** (Réf. 7360) : correction dans INGENEO PRECOMPTA.
* **Menu `Bannettes` : détection de doublon sur le même document** (Réf. 7371) : correction dans INGENEO PRECOMPTA.
* **Banque : incident sur l'enregistrement des mots-clés** (Réf. 7327) : correction dans INGENEO PRECOMPTA.
* **Menu `Bannettes` / Banque : affichage décalé lorsque l'on change le mode de regroupement** (Réf. 7344) : dans INGENEO PRECOMPTA, l'affichage n'est plus décalé lors d'un changement du mode de regroupement.
* **Facture électronique : réception dans le premier classeur par défaut (numéro d'ordre)** (Réf. 7206) : correction dans INGENEO PRECOMPTA.
* **Saisie impossible d'un IBAN alphanumérique** (Réf. 7298) : dans INGENEO PRECOMPTA, la saisie d'un IBAN alphanumérique est de nouveau possible.

## Version 2.9.5 – 2026-09-10

### <i class="fa-sparkles">:sparkles:</i>Nouveautés

* **Mention d'un utilisateur et lien dans le mail** (Réf. 1507) : nouveauté dans INGENEO PRECOMPTA.
* **EVOL : Modèle d'entreprise - Création de plusieurs classeurs d'achat et/ou vente** (Réf. 2859) : nouveauté dans INGENEO PRECOMPTA.
* **Information complémentaire en saisie libre** (Réf. 6368) : nouveauté dans INGENEO PRECOMPTA.
* **Masquer entreprise de la vue mandats et enrôlements PA** (Réf. 6657) : dans INGENEO PRECOMPTA, vous pouvez masquer une entreprise de la vue mandats et enrôlements PA.
* **Menu `Bannettes` : modifier / supprimer des informations complémentaires** (Réf. 6835) : dans INGENEO PRECOMPTA, menu `Bannettes`, vous pouvez modifier ou supprimer des informations complémentaires.
* **Ajout de l'URL et de l'information complémentaire dans l'export Excel de la liste des écritures** (Réf. 6836) : dans INGENEO PRECOMPTA, l'export Excel de la liste des écritures contient l'URL et l'information complémentaire.
* **Plateforme avec PDS activé mais réception facture sur INGENEO PRECOMPTA** (Réf. 6863) : nouveauté dans INGENEO PRECOMPTA.

### <i class="fa-wrench">:wrench:</i>Corrections

* **Bug dans la remontée des informations "établissement"** (Réf. 6352) : correction dans INGENEO PRECOMPTA.
* **Informations de maillage non reprises dans le modèle d'accord de PA** (Réf. 6787) : dans INGENEO PRECOMPTA, les informations de maillage sont reprises dans le modèle d'accord de PA.
* **Enrôlement : erreur `L'adresse du siège de l'établissement doit être complète`** (Réf. 6921) : correction dans INGENEO PRECOMPTA.
* **Enrôlement : filtre incohérent** (Réf. 6950) : correction dans INGENEO PRECOMPTA.
* **Bouton assistant d'enrôlement non présent** (Réf. 6986) : dans INGENEO PRECOMPTA, le bouton assistant d'enrôlement est présent.
* **Enrôlement : bloqué car anomalie remontée du siège** (Réf. 7020) : correction dans INGENEO PRECOMPTA.
* **Menu `Bannettes` : découpage manuel avec documents Factur-X** (Réf. 3207) : correction dans INGENEO PRECOMPTA.
* **Perte du contenu d'un document lors d'un découpage manuel** (Réf. 5707) : dans INGENEO PRECOMPTA, le découpage manuel d'un document ne fait plus perdre son contenu.
* **Découpage manuel : affichage de page blanche** (Réf. 5838) : dans INGENEO PRECOMPTA, le découpage manuel n'affiche plus de page blanche.
* **Déplacement documents impossible - autres documents** (Réf. 6557) : dans INGENEO PRECOMPTA, le déplacement des autres documents est de nouveau possible.
* **Menu `Bannettes` : double barre de défilement lorsqu'il y a beaucoup de lignes d'imputation** (Réf. 6827) : dans INGENEO PRECOMPTA, menu `Bannettes`, la double barre de défilement n'apparaît plus avec beaucoup de lignes d'imputation.
* **Menu `Bannettes` : saisie & analytiques obligatoires - appliquer l'obligation sur la première section** (Réf. 6874) : correction dans INGENEO PRECOMPTA.
* **Affichage documents enregistrés : compteur KO (Entreprise)** (Réf. 6945) : correction dans INGENEO PRECOMPTA.
* **Nombre de documents incohérent dans le menu `Bannettes`** (Réf. 6953) : correction dans INGENEO PRECOMPTA.
* **Engagement de dépense : erreur 500** (Réf. 7039) : correction dans INGENEO PRECOMPTA.
* **Fenêtre de mise à jour des IBAN en arrière-plan** (Réf. 7034) : correction dans INGENEO PRECOMPTA.
* **Tampon : position différente sur INGENEO PRECOMPTA et à l'export** (Réf. 7096) : dans INGENEO PRECOMPTA, la position du tampon est identique à l'écran et à l'export.
* **Entreprise : intégration d'un FEC - collectifs rattachés aux tiers, mais ne remonte pas dans le plan comptable** (Réf. 7097) : correction dans INGENEO PRECOMPTA.
* **Modification des classeurs comptables impossible** (Réf. 7111) : dans INGENEO PRECOMPTA, la modification des classeurs comptables est de nouveau possible.
* **Reconnaissance MAPS** (Réf. 6613) : correction dans INGENEO PRECOMPTA.
