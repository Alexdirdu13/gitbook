# Août - 2026

## Version 2.9.2 – 2026-08-25

### <i class="fa-sparkles">:sparkles:</i>Nouveautés

* **Paramétrage entreprise : personnalisation des libellés de sections analytiques** (Réf. 6423) : dans INGENEO PRECOMPTA, paramétrage entreprise, vous pouvez personnaliser les libellés des sections analytiques.

### <i class="fa-wrench">:wrench:</i>Corrections

* **Changement statut Mandat** (Réf. 6402) : correction dans INGENEO PRECOMPTA.
* **Enrôlement : Erreur EISP sur SIREN qui débute par un 0** (Réf. 6716) : dans INGENEO PRECOMPTA, l'enrôlement d'une entreprise dont le SIREN débute par un 0 ne génère plus l'erreur EISP.
* **Mandats : incohérence sur le filtre `Infos manquantes` (nombre d'entreprise) dans le fichier d'export** (Réf. 6782) : correction dans INGENEO PRECOMPTA.
* **Incohérence d'affichage du nombre de droits attribués sur les circuits de validation + options gestionnaires** (Réf. 6113) : correction dans INGENEO PRECOMPTA.
* **Déplacement tampons** (Réf. 6727) : correction dans INGENEO PRECOMPTA.
* **Paramétrage entreprise : la plateforme affiche la date de création d'entreprise comme date de fermeture** (Réf. 6509) : correction dans INGENEO PRECOMPTA.
* **Paramétrage entreprise : paramétrage section analytique (valeur identique sur les sections après enregistrement alors que le paramétrage est différent)** (Réf. 6559) : correction dans INGENEO PRECOMPTA.
* **Type de comptabilité : impossible de mettre Engagement sur SCI/LMNP/BNC** (Réf. 6651) : dans INGENEO PRECOMPTA, le type de comptabilité Engagement peut être sélectionné pour les SCI, LMNP et BNC.
* **Import en masse dossiers : non application du modèle** (Réf. 6658) : dans INGENEO PRECOMPTA, l'import en masse des dossiers applique le modèle.
* **Powens : absence de remontée des mouvements bancaires** (Réf. 6647) : dans INGENEO PRECOMPTA, les mouvements bancaires remontent depuis Powens.

## Version 2.9.0 – 2026-08-13

### <i class="fa-sparkles">:sparkles:</i>Nouveautés

* **Enrôlement : Options `Assistant d'enrôlement Entreprise`** (Réf. 6274) : nouveauté dans INGENEO PRECOMPTA.

### <i class="fa-wrench">:wrench:</i>Corrections

* **Colonnes Nom/Prénom inversées lors de l'extraction du fichier de MAJ des informations manquantes** (Réf. 6666) : dans INGENEO PRECOMPTA, les colonnes Nom et Prénom ne sont plus inversées dans le fichier de mise à jour des informations manquantes.
* **depot mandat zip impossible** (Réf. 6646) : dans INGENEO PRECOMPTA, le dépôt de mandats en fichier .zip est de nouveau possible.
* **Import en masse informations manquantes mandats / enrôlements bien fonctionnel (en se basant sur le modèle)** (Réf. 6472) : dans INGENEO PRECOMPTA, l'import en masse des informations manquantes des mandats et enrôlements fonctionne à partir du modèle.
* **Vue enrôlement : accès uniquement aux mandats/enrôlements des dossiers pour lesquels on a des droits** (Réf. 6436) : dans INGENEO PRECOMPTA, la vue enrôlement donne accès uniquement aux mandats et enrôlements des dossiers sur lesquels l'utilisateur a des droits.
* **Problème de visualisation des devis - 3eme niveau de validation** (Réf. 4345) : correction dans INGENEO PRECOMPTA.
* **Modification de compte impossible depuis notifications suite à un refus circuit de validation** (Réf. 5503) : dans INGENEO PRECOMPTA, après un refus dans un circuit de validation, la modification de compte depuis les notifications est de nouveau possible.
* **Application aléatoire du tampon dans un circuit de validation** (Réf. 6039) : dans INGENEO PRECOMPTA, le tampon ne s'applique plus de façon aléatoire dans un circuit de validation.
* **Tampon : Couleurs non appliquées** (Réf. 6320) : dans INGENEO PRECOMPTA, les couleurs du tampon sont appliquées.
* **Disparition du Dual Screen à la création d'un tiers** (Réf. 6410) : dans INGENEO PRECOMPTA, le Dual Screen ne disparaît plus à la création d'un tiers.
* **Duplication de sites lors d'un import d'entreprise** (Réf. 6432) : dans INGENEO PRECOMPTA, l'import d'entreprise ne duplique plus les sites.
* **Bug coche `Entreprise non assujettie à la TVA.`** (Réf. 6519) : correction dans INGENEO PRECOMPTA.
* **Modèle d'import d'entreprise non actualisé suite au changement de libellé du mode de facturation** (Réf. 6628) : dans INGENEO PRECOMPTA, le modèle d'import d'entreprise est actualisé après le changement de libellé du mode de facturation.
* **Impossible de sélectionner l'année 2026 suite à l'import du bareme IK** (Réf. 6633) : dans INGENEO PRECOMPTA, après l'import du barème IK, l'année 2026 peut être sélectionnée.
