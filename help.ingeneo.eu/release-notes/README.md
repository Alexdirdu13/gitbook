# Release notes

Une release note présente les changements apportés par une version d'INGENEO PRECOMPTA. Chaque version est identifiée par un numéro au format X.Y.Z et par sa date de mise à disposition.

Les changements de chaque version sont classés en trois rubriques :

* **Nouveautés** : fonctionnalités ajoutées dans INGENEO PRECOMPTA.
* **Améliorations** : évolutions de fonctionnalités existantes d'INGENEO PRECOMPTA.
* **Corrections** : anomalies corrigées dans INGENEO PRECOMPTA.

Les release notes sont regroupées par mois, du plus récent au plus ancien. Sélectionnez un mois pour consulter ses versions.
