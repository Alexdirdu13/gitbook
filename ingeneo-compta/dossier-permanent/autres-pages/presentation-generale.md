# Présentation générale

{% hint style="success" %}
**En bref** — Cette page présente le module « Dossier permanent », qui rassemble les informations de la société non propres à un dossier annuel : identité, partenaires, données sociales, fiscales et juridiques, et fichiers de paramétrage.

* Pour commencer : ouvrez le module, le logiciel affiche directement la fiche de la société (menu « Identité », sous-option « Fiche société »).
* Pour accéder aux fichiers « Taxes » et « Banques » : entrée « Préférences » de la barre latérale, rubrique « Données », onglet « Dossier et comptabilité ».
{% endhint %}

Le module ne possède pas d'écran d'accueil : lorsque vous ouvrez le module « Dossier permanent », le logiciel affiche directement la fiche de la société (menu « Identité », sous-option « Fiche société »).

Le menu du module comporte six options. Cinq d'entre elles donnent accès à plusieurs sous-options, la dernière à une seule :

* « Identité » : « Fiche société », « Activité », « Documents divers »,
* « Partenaires » : « Expert-Comptable », « Commissaires aux comptes », « Financiers », « Conseillers juridiques », « Sous-traitants », « Autres interlocuteurs »,
* « Social » : « Effectifs », « Etablissements », « Conventions collectives », « Accords d'entreprise », « Organismes sociaux », « Contrôles URSSAF », « Rescrits sociaux », « Représentants du personnel », « Autres informations sociales »,
* « Fiscal » : « Impôts directs », « TVA », « Autres taxes », « Organismes de gestion agréés », « Prestataire ECF », « SIE », « Contrôles fiscaux », « Rescrits fiscaux », « Autres informations fiscales »,
* « Juridique » : « Informations générales », « Statuts », « Kbis », « Conventions règlementées », « Procès-verbaux », « Autres documents légaux », « Actionnaires - personnes morales », « Actionnaires - personnes physiques », « Filiales et participations »,
* « Editions » : « Générateur d'états ».

Les deux fichiers de paramétrage du module, « Taxes » et « Banques », ne figurent pas dans ce menu : vous les ouvrez depuis le panneau « Paramètres » (entrée « Paramètres », roue dentée, de la navigation latérale ; hors tableau de bord, cette barre est masquée : cliquez sur le bord gauche de l'écran pour l'ouvrir), rubrique « Données », onglet « Dossier et comptabilité ».

Les informations du Dossier permanent sont attachées à la société, et non au dossier annuel en cours : lorsque vous les modifiez, la modification vaut pour tous les dossiers annuels non clôturés de la société.

Certains écrans du module se servent des données saisies dans d'autres : le menu « Fiscal », sous-option « Autres taxes », propose les taxes créées dans l'option « Taxes » du panneau « Paramètres », et les établissements créés dans le menu « Social », sous-option « Etablissements ». Si l'une de ces deux listes vous paraît vide, c'est que l'écran qui l'alimente n'a pas encore été renseigné.

Chaque sous-option est décrite dans le chapitre qui lui correspond.
