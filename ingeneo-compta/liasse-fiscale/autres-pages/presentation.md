# Présentation

{% hint style="success" %}
**En bref** — Cette page présente le module Liasse fiscale : établir les documents fiscaux d'un dossier annuel, les contrôler, puis les télétransmettre à l'administration fiscale par un partenaire EDI.

* Pour établir une déclaration (liasse, CVAE, annexe) : ouvrez le menu "Liasse fiscale" et créez un document du type approprié.
* Pour régler les acomptes et le solde d'un impôt : ouvrez le menu du même nom ("CVAE", "IS", "RCM" ou "TS").
* Pour régler le module : ouvrez le panneau "Paramètres" par l'entrée "Préférences", rubrique "Liasse fiscale", onglet "Configuration".
{% endhint %}

Le module "Liasse fiscale" permet d'établir les documents fiscaux légaux d'un dossier annuel, de les contrôler, puis de les télétransmettre à l'administration fiscale par l'intermédiaire d'un partenaire EDI.

Ces documents sont alimentés principalement par les données du module "Comptabilité" ou "Comptabilité expert", mais aussi par celles d'autres modules tels que "Immobilisations" ou "Dossier permanent". Vous n'avez donc pas à ressaisir dans une déclaration ce qui a déjà été saisi ailleurs : vous complétez, vous vérifiez, puis vous transmettez.

## Ce que le module produit

Chaque document que vous créez dans le module — quel que soit le menu — se présente de la même façon : une **fiche d'identification**, où vous indiquez notamment le millésime de la campagne déclarative, le type de déclaration et le partenaire EDI qui assurera la transmission, puis un **écran de saisie des formulaires**, où vous complétez les imprimés eux-mêmes.

Les menus se répartissent en trois familles.

**Les déclarations**

Le menu "Liasse fiscale" porte la liasse elle-même et son annexe des comptes annuels, dans tous les régimes que vous êtes susceptible d'établir. C'est aussi par lui que passent certaines déclarations qui n'ont pas de menu propre, dont la déclaration de CVAE.

Le menu "Annexe asso" est réservé à l'annexe des comptes annuels des **associations non fiscalisées** : pour les associations fiscalisées, revenez au menu "Liasse fiscale".

Les menus "DAS2" et "IFU" portent les déclarations annuelles du même nom, et la rubrique "Déclarations des loyers" la déclaration des loyers, précédée des deux options qui permettent de demander la liste des locaux à la DGFiP puis de la consulter.

**Les paiements**

Les menus "CVAE", "IS", "RCM" et "TS" servent aux **paiements** — acomptes et liquidations — et non aux déclarations correspondantes.

C'est le point à retenir avant d'ouvrir l'un de ces menus, car la confusion est facile : pour la déclaration, c'est le menu "Liasse fiscale" et un document du type approprié ; pour en régler les acomptes et le solde, c'est le menu du même nom que l'impôt.

**Le suivi et le paramétrage**

Le menu "Signatures" récapitule les documents du module envoyés en signature électronique, avec la date et l'heure de l'envoi, son auteur, ses destinataires, le statut de la signature et la date de ce statut.

Les réglages du module n'ont plus de menu dans la barre du module : ils se trouvent dans le panneau "Paramètres", que vous ouvrez par l'entrée "Paramètres" de la barre latérale (en bas de la liste ; hors tableau de bord, ouvrez d'abord la barre par la poignée du bord gauche). Les réglages propres au module sont à la rubrique "Liasse fiscale", onglet "Configuration" ; les réglages partagés avec les autres modules à la rubrique "Généraux", onglet "Configuration" ; les modèles d'e-mails, qui servent aux envois, à la rubrique "Modèles", onglet "E-mails".

## Ce qui est commun à tous les documents du module

Quel que soit le menu, vous retrouvez les mêmes notions, et il est utile de les avoir en tête avant votre première déclaration.

| Champ                       | Ce qu'il faut savoir                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Le millésime**            | Une déclaration est toujours rattachée à une campagne déclarative, qui a une date de début et une date de fin.                                                                                                                                                                                                                                                                                                                       |
| **Le partenaire EDI**       | La transmission ne se fait pas en direct, mais par un partenaire que vous choisissez document par document. Quatre partenaires sont proposés : "Jedeclare.com", "ASP ONE", "NET DECLARATION" et "TDNIM".                                                                                                                                                                                                                             |
| **L'archivage dans la GED** | Le module enregistre automatiquement dans la GED une déclaration une fois sa transmission réussie, hors déclarations de test ; un bouton « Archiver en GED » de l'écran de saisie des formulaires permet aussi de l'archiver à la main. Cet archivage se règle dans le panneau "Paramètres", rubrique "Liasse fiscale", onglet "Configuration", par la question « Souhaitez-vous archiver dans la GED les déclarations validées ? ». |

## Où trouver le détail

Le fonctionnement complet d'un document — la liste des formulaires, la saisie des cellules, les contrôles, l'édition et la demande de télétransmission — est décrit une seule fois, dans l'option "Liasse fiscale" de la présente aide. Les autres options ne reprennent que ce qui leur est propre et y renvoient pour le reste.
