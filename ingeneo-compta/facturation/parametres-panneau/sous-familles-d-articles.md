# Sous-familles d'articles

{% hint style="info" %}
**Où le trouver :** Panneau **Paramètres** › **Données** › **Tiers et commercial** › **Sous-familles d'articles**
{% endhint %}

{% hint style="success" %}
**En bref** — Les sous-familles subdivisent les familles d'articles en groupes plus précis. Ce fichier n'est accessible que si l'option « Utiliser les sous-familles d'articles » est activée.

* Si l'écran affiche « Vous n'avez pas activé la gestion des sous-familles. » : activez d'abord les familles, puis « Utiliser les sous-familles d'articles », dans « Paramètres » > « Facturation » > « Articles ».
{% endhint %}

Les sous-familles d'articles permettent de subdiviser les familles d'articles en groupes plus précis.

Cet écran s'ouvre par le panneau « Paramètres » : rubrique « Données », groupe « Tiers et commercial », entrée « Sous-familles d'articles ».

Ce fichier n'est accessible que si vous avez activé l'interrupteur « Utiliser les sous-familles d'articles » dans le panneau « Paramètres » : rubrique « Facturation », écran « Articles », rubrique « Options de gestion des articles ». Cette option n'est elle-même activable qu'après l'option « Utiliser les familles d'articles » : les sous-familles supposent donc les familles.

Tant que la gestion des sous-familles est désactivée, l'entrée « Sous-familles d'articles » reste présente dans le groupe « Tiers et commercial » et reste cliquable, mais l'écran ne présente ni liste, ni fiche, ni bouton : sous le sous-titre « Propre au dossier annuel » et un bandeau d'information, il affiche uniquement le message « Vous n'avez pas activé la gestion des sous-familles. »

Ce message ne diffère que d'un mot de celui de l'écran « Familles d'articles », qui dit « la gestion des familles » : les deux options sont distinctes et se règlent séparément.
