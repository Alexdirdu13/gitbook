# Média — présentation générale

{% hint style="success" %}
**En bref** — La fonction « Média » diffuse des informations aux utilisateurs : chacun voit dans son tableau de bord les informations partageant au moins un tag avec les siens.

* Pour diffuser une information : créez les tags dans « Tags », rédigez l'information dans « Informations », puis affectez les tags aux utilisateurs dans « Paramétrage utilisateurs ».
{% endhint %}

La fonction "Média" permet de créer des informations et de les diffuser auprès de tout ou partie des utilisateurs du logiciel.

Des mots-clefs (tags) sont affectés à chaque information et ces mêmes tags sont affectés aux utilisateurs.

Chaque utilisateur visualisera dans le tableau de bord les informations qui contiennent au moins un même tag que ceux qui lui ont été affectés dans sa fiche.

La fonction se compose de quatre options. Elles s'utilisent dans l'ordre suivant, qui n'est pas celui du menu : celui-ci présente "Informations" avant "Tags".

| Champ                        | Ce qu'il faut savoir                                                                                      |
| ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Tags**                     | Vous y créez le référentiel des mots-clefs. Les trois autres options ne proposent que les tags créés ici. |
| **Informations**             | Vous y rédigez les informations à diffuser et vous affectez à chacune un ou plusieurs tags.               |
| **Paramétrage utilisateurs** | Vous y affectez jusqu'à dix tags à chaque utilisateur.                                                    |
| **Statistiques**             | Vous y éditez, par mois ou par année, les statistiques de consultation des informations diffusées.        |

{% hint style="info" %}
Notez que ce que vous paramétrez ici est vu par quelqu'un d'autre que vous : les informations et les tags que vous saisissez déterminent ce qui s'affichera dans le tableau de bord des utilisateurs.
{% endhint %}
