# Documents — présentation générale

{% hint style="success" %}
**En bref** — Cette option soumet des documents à la validation des utilisateurs et suit leurs validations ; vous pouvez bloquer l'accès à l'application tant qu'un document n'est pas validé.

* Pour soumettre un document : option « En cours ».
* Pour retrouver un document archivé : option « Archivés ».
{% endhint %}

Cette option permet de gérer la validation de documents par les utilisateurs de l'application.

Les documents peuvent être de toutes natures telles que des nouvelles conditions générales de vente pour les clients ou des nouvelles procédures pour les salariés.

Vous avez la possibilité d'interdire l'accès à l'application tant que l'utilisateur n'a pas validé le ou les document(s) que vous lui avez affecté(s).

Cette rubrique se distingue des autres : ailleurs, vous préparez ce que vos destinataires verront ; ici, vous leur soumettez un document et vous suivez leurs validations.

Le circuit se lit en deux temps, correspondant aux deux options de la rubrique :

* l'option « En cours » porte les documents que le logiciel présente à chaque connexion des destinataires qui ne les ont pas encore validés. Un document y reste tant qu'il n'a pas été archivé ;
* l'option « Archivés » conserve l'historique des documents que vous avez archivés.
