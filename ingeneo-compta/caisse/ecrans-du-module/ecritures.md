# Ecritures

{% hint style="info" %}
**Où le trouver :** Menu **Ecritures**
{% endhint %}

{% hint style="success" %}
**En bref** — Si les écritures ne sont pas générées directement en comptabilité, cet écran liste celles produites à la validation des journées de caisse et vous permet de les exporter vers votre logiciel de comptabilité.

* Pour retrouver des écritures : réglez les filtres « Journal », « Origine », « Date de début » et « Date de fin » ; la liste se recharge aussitôt.
* Pour exporter : bouton \[Exporter], choisissez le « Modèle », puis bouton \[Exporter] de la fenêtre.
* Pour revoir des écritures déjà exportées : activez l'interrupteur « Avec les lignes déjà exportées ».
{% endhint %}

Si vous n'avez pas retenu la génération directe, cette option contient toutes les écritures générées par le module Caisse à la validation des journées de caisse, et vous permet de les exporter de manière différée vers le module Comptabilité ou vers un autre logiciel de comptabilité.

<figure><img src="../../.gitbook/assets/31-cm304.png" alt="Écran Ecritures"><figcaption><p>Écran « Ecritures » de la nouvelle interface</p></figcaption></figure>

Si des écritures ont été générées par d'autres modules, tels que l'OCR ou Scrap banque, elles y figurent également et sont exportables.

L'écran se compose du récapitulatif des totaux, placé au-dessus de la liste, des filtres, de la liste des écritures, puis du bouton \[Exporter], en bas de l'écran.

Le le choix des colonnes affichées se fait par le bouton **\[Vue]**, dont le fonctionnement, commun à toutes les listes, est décrit dans la page commune « Les listes ».

**a) Totaux**

Au-dessus de la liste, à droite, le logiciel totalise les écritures : « Débit », « Crédit » et « Solde ». Ils sont là pour vous permettre de contrôler.

**b) Sélecteur « Journal »**

Premier filtre de la zone, il vous permet de ne retenir que les écritures d'un code journal.

**c) Sélecteur « Origine »**

Il vous permet de ne retenir que les écritures générées par l'un des modules Ingeneo Compta.

**d) Zones « Date de début » et « Date de fin »**

Elles bornent la période des écritures affichées. Le logiciel les préremplit avec les dates de début et de fin de la période de saisie de votre dossier annuel. Vous les modifiez à la main.

**e) Interrupteur « Avec les lignes déjà exportées »**

Désactivé — sa position à l'ouverture de l'écran — il laisse la liste ne présenter que les écritures qui n'ont pas encore été exportées. Activez-le pour faire apparaître également celles que vous avez déjà exportées.

**f) Application des filtres**

Les filtres s'appliquent dès que vous en modifiez un : la liste se recharge.

**g) Barre de la liste**

La liste présente aussi une barre de recherche, bouton **\[Filtres]** et bouton **\[Vue]**. Leur fonctionnement, commun à toutes les listes, est décrit dans la page commune « Les listes ».

**h) Pictogramme « Œil »**

Si une pièce a été associée à une ligne d'écriture, le pictogramme « Œil » apparaît sur cette ligne, avec l'infobulle « Afficher l'aperçu », et le clic vous remet le fichier de la pièce. Sur les lignes auxquelles aucune pièce n'est associée, le pictogramme n'apparaît pas.

**i) Bouton \[Exporter]**

Il ouvre la fenêtre « Export », dans laquelle vous choisissez un modèle.

**Modèle** : indiquez le modèle d'export sur la base duquel le fichier sera constitué ; c'est lui qui détermine la forme du fichier produit. Si le modèle dont vous avez besoin ne figure pas dans la liste, vous avez la possibilité de le créer dans le panneau « Paramètres », rubrique « Modèles », « Imports et exports », « Écritures ».

Le Bouton \[Exporter] de la fenêtre lance l'export avec le modèle choisi.

Un second Bouton \[Exporter les pièces jointes] ne vous est proposé que si le modèle d'export retenu prévoit l'export des pièces jointes.

Le bouton \[Exporter] de l'écran est soumis à autorisation : selon votre profil, il peut ne pas vous être proposé.
