# États financiers

{% hint style="info" %}
**Où le trouver :** Panneau **Paramètres** › **Modèles** › **Documents** › **États financiers**
{% endhint %}

Un modèle d'état financier décrit la présentation d'une édition comptable : ses colonnes, sa ligne d'en-tête et ses lignes de détail (compte, écriture, ventilation analytique). Il existe quatre types de modèle : **Compte de résultat**, **SIG** (soldes intermédiaires de gestion), **Bilan** et **Indicateur**.

Dans une plaquette, vous insérez un état financier par l'élément « État financier » : vous y choisissez le type de modèle, puis le modèle d'édition parmi ceux de ce type (voir la page « Plaquettes »). Les modèles se gèrent dans le panneau « Paramètres », par la navigation de gauche : rubrique « Modèles », puis « Documents », entrée « États financiers ». Ce panneau est global : vous l'ouvrez de la même façon depuis chaque module.

## La liste des modèles

L'écran est signalé « Propre au dossier annuel » et porte ce bandeau : « Un modèle d'état financier décrit la présentation d'une édition comptable : ses colonnes, sa ligne d'en-tête et ses lignes de détail (compte, écriture, ventilation analytique). »

Au-dessus de la grille :

* le champ « Rechercher un état financier… » (raccourci « / ») ;
* le bouton **\[Filtres]** ;
* la liste **Type de modèle** (Compte de résultat, SIG, Bilan, Indicateur), qui restreint l'affichage à un type ;
* le bouton **\[Vue]** (raccourci Ctrl+Maj+V), qui permet d'enregistrer une présentation (« MES VUES ») et de choisir les colonnes affichées ; « Rétablir les colonnes d'origine » revient à l'affichage initial et bouton **\[Appliquer]** valide ;
* le bouton **\[Exporter]**.

La grille affiche par défaut le **Libellé** (tri croissant), le **Type de modèle** et la **Description**, puis une colonne de commandes, le menu « Autres actions ». Le choix des colonnes permet d'afficher aussi la date de création, la date de modification, « Modèle éditeur » et le compte de rattachement.

Les modèles fournis par l'éditeur ont un libellé écrit entre astérisques, par exemple « _Bilan BIC_ », « _Bilan Association_ » ou, pour les indicateurs, « _Achats - Frais accessoires_ ». Leur description indique la date de leur dernière mise à jour. Le menu « Autres actions » d'un modèle de l'éditeur propose **Dupliquer** et **Supprimer**, sans « Modifier ».

Quand une ligne est cochée, une barre apparaît au pied de la grille : « n état financier sélectionné · Tout désélectionner », avec bouton **\[Supprimer]** et bouton **\[Exporter]**. La pagination s'accompagne de « Sélectionner la page » et « Tout sélectionner ».

Le pied de l'écran porte bouton **\[Créer un état financier]** et bouton **\[Charger les nouveaux modèles]**.

## La fiche d'un modèle

La fiche s'ouvre par bouton **\[Créer un état financier]**. Une flèche de retour « ‹ » figure dans la barre d'onglets, et le bouton **\[Enregistrer]** termine la fiche. Si vous quittez la fiche alors que des champs sont saisis, le logiciel ouvre la fenêtre « Modifications non enregistrées » : « Attention, vous avez des modifications non enregistrées. Souhaitez-vous continuer ? », avec bouton **\[Continuer sans enregistrer]** (en rouge) et bouton **\[Enregistrer et quitter]**.

**Les contrôles à l'enregistrement.** Le logiciel refuse d'enregistrer un modèle :

* dont le libellé est déjà utilisé (« Libellé déjà utilisé ») ;
* qui, pour un compte de résultat ou des SIG, ne comporte pas exactement une ligne de chiffre d'affaires et une ligne de résultat ; pour un bilan, qui ne comporte pas exactement une ligne de total actif et une ligne de total passif ;
* dans lequel une même racine de compte figure dans plusieurs agrégats (« Les comptes de racines … sont présents plusieurs fois. ») ;
* dont un agrégat reprend une ligne inexistante ou postérieure à lui.

Les lignes du type « Ligne sans contrôle » échappent au contrôle des racines de compte en double : vous pouvez y reprendre des comptes déjà utilisés ailleurs dans le modèle, par exemple pour un récapitulatif.
