# OCR\_C2\_Fichiers\_REVISION

{% hint style="success" %}
**En bref** — La rubrique « Fichiers » n'existe plus dans la barre du module : ses écrans de paramétrage se trouvent désormais dans le panneau Paramètres.

* Pour le plan comptable, les comptes auxiliaires, les journaux, les codes TVA, les modes et délais de règlement : panneau Paramètres, rubrique « Données », menu « Dossier et comptabilité ».
* Pour les circuits d'approbation : rubrique « Données », menu « Intégrations et workflow », écran « Circuits de validation ».
{% endhint %}

Cette rubrique n'existe plus dans la barre du module OCR, qui ne porte plus que « Saisies », « Ecritures » et « Editions » : ses écrans se trouvent désormais dans le panneau Paramètres, ouvert par l'entrée « Paramètres » (roue dentée) de la barre latérale ; hors tableau de bord, cliquez d'abord la flèche du bord gauche de l'écran pour ouvrir la barre. Ils permettent de paramétrer les différents éléments nécessaires à la génération des écritures comptables et au traitement des pièces :

* le **plan comptable** et les **comptes auxiliaires**, les **journaux** et les **codes TVA**, les **modes de règlement** et les **délais de règlement** : rubrique « Données », menu « Dossier et comptabilité »,
* les **circuits d'approbation** : rubrique « Données », menu « Intégrations et workflow », écran « Circuits de validation ».
