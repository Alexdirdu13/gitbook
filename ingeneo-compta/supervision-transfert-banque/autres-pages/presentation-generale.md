# Présentation générale

{% hint style="success" %}
**En bref** — Le module « Supervision transfert banque » reçoit des relevés bancaires transmis globalement et les répartit dans les sociétés gérées correspondantes pour en générer des écritures comptables.

* Pour importer des relevés manuellement : ouvrez l'option « Imports ».
* Pour désigner les sociétés et les banques concernées par le transfert : ouvrez l'option « Sociétés gérées ».
{% endhint %}

Le module « Supervision transfert banque » permet de recevoir des relevés bancaires transmis globalement et de les répartir dans les comptes des sociétés gérées correspondantes afin d'en générer des écritures comptables.

Ces relevés peuvent être importés manuellement dans l'option « Imports », ou récupérés automatiquement pendant la nuit auprès des services que vous avez activés dans le panneau « Paramètres », rubrique « Supervision transfert banque », onglet « Configuration ».

Vous désignez, dans l'option « Sociétés gérées », les sociétés concernées par le transfert et les banques dont vous souhaitez récupérer les relevés.
