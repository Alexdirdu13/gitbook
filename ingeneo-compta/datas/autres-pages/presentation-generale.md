# Présentation générale

{% hint style="success" %}
**En bref** — Le module « Datas » recueille les écritures comptables produites par d'autres logiciels, les DSN et vos données externes, qui servent de matière aux indicateurs des modules « Vision » et « Vision expert ».

* Pour débuter : décrivez la forme de vos fichiers dans le panneau Paramètres, onglet « Modèles », « Imports et exports », « Écritures ».
* Pour faire entrer et corriger vos écritures : menu « Ecritures », sous-menu « Import de données ».
* Pour consulter les écritures présentes : menu « Ecritures », sous-menu « Visualisation ».
{% endhint %}

## Ce que contient le module

Le menu « Ecritures » réunit les deux options qui concernent les écritures comptables : l'option « Import de données », où vous faites entrer un fichier et où vous corrigez les lignes que le logiciel signale en anomalie, et l'option « Visualisation », qui vous montre les lignes d'écritures présentes dans le module.

L'entrée « DSN » de la barre de menus vous permet de faire entrer des déclarations sociales nominatives et de consulter celles qui ont déjà été reçues.

L'entrée « Données externes » de la barre de menus vous permet de créer et de tenir à jour vos données complémentaires.

Le menu « Editions » ne comporte que l'option « Générateur d'états », avec laquelle vous bâtissez vos propres éditions ; son aide, commune à tous les modules où il est présent, se trouve dans le chapitre « Généralités » en tête de la présente aide.

Le paramétrage du module ne se trouve plus dans la barre de menus : il est dans le panneau Paramètres, que vous ouvrez par l'entrée « Paramètres » en bas de la barre latérale gauche (hors tableau de bord, cette barre est masquée : cliquez sur le bord gauche de l'écran pour l'ouvrir). Sa rubrique « Datas » réunit deux onglets : « Configuration », qui porte l'identification de la société gérée, les connecteurs qui l'alimentent et le transfert automatique des écritures en comptabilité ; et « Filtrage des e-mails », où vous dites quelles adresses ont le droit d'envoyer des fichiers à la société gérée. Les modèles d'import export, où vous décrivez la forme des fichiers que vous recevez, sont dans l'onglet « Modèles » du même panneau, sous « Imports et exports », « Écritures ».

## Débuter avec le module « Datas »

Le module s'emploie dans cet ordre :

* décrivez d'abord la forme des fichiers que vous recevez, dans le panneau Paramètres, onglet « Modèles », « Imports et exports », « Écritures » ;
* indiquez ensuite, dans le panneau Paramètres, rubrique « Datas », onglet « Configuration », le connecteur qui alimentera cette société gérée, et dites si les écritures reçues doivent être transférées automatiquement dans le module de comptabilité ;
* si vos fichiers vous parviennent par courrier électronique, indiquez quelles adresses vous autorisez, dans le panneau Paramètres, rubrique « Datas », onglet « Filtrage des e-mails » ;
* faites entrer vos écritures, et corrigez celles qui présentent une anomalie, dans le menu « Ecritures », sous-menu « Import de données » ;
* consultez à tout moment les écritures présentes dans le module par le menu « Ecritures », sous-menu « Visualisation ».
