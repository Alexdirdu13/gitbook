# Editions

{% hint style="success" %}
**En bref** — Cette page présente les éditions du module : liste des actions, tableau mensuel, tableau annuel et absences, ainsi que le générateur d'états pour composer vos propres éditions.

* Pour éditer vos temps : choisissez « Liste des actions », « Tableau mensuel » ou « Tableau annuel », renseignez les filtres, puis lancez l'édition.
{% endhint %}

Cette rubrique rassemble les éditions du module. Vous y retrouvez les temps de travail que vous avez saisis, ainsi que ceux des autres intervenants, sous trois présentations : ligne par ligne sur une période, sous la sous-rubrique « Liste des actions » ; jour par jour pour un mois, sous « Tableau mensuel » ; mois par mois pour une année, sous « Tableau annuel ». La sous-rubrique « Absences » édite, elle, les absences sur une période.

Ces quatre éditions se préparent de la même façon : l'écran ne sert qu'à définir les filtres, les critères et le format que vous souhaitez, rien n'y est enregistré, et le logiciel produit l'état : au format Html il s'ouvre dans un nouvel onglet de votre navigateur, tandis qu'aux formats Pdf et Excel le fichier vous est remis par votre navigateur.

La sous-rubrique « Générateur d'états » vous permet en outre de composer vous-même des éditions à partir des fichiers du module, et de les mémoriser pour les relancer ensuite. Elle est commune à tous les modules où elle est présente : son aide se trouve dans le chapitre « Généralités » en tête de la présente aide.
