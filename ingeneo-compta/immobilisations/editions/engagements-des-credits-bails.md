# Engagements des crédits-bails

{% hint style="info" %}
**Où le trouver :** Menu **Éditions › Engagements des crédits-bails**
{% endhint %}

{% hint style="success" %}
**En bref** — Cette édition présente les engagements que vos crédits-bails font peser sur les exercices à venir, à partir des échéanciers calculés sur chaque fiche.

* Pour éditer les engagements : indiquez la date du calcul, choisissez le tri et le format, puis bouton \[Editer].
* Pour obtenir le sous-total mobilier/immobilier : retenez le tri « Comptes de loyers », les deux racines de loyers devant être renseignées dans le panneau « Paramètres », rubrique « Immobilisations », option « Comptes ».
{% endhint %}

## Rubrique « Choix des critères »

**Date du calcul** : Le logiciel propose la date de fin de votre exercice. Saisissez-la, ou choisissez-la à l'aide du pictogramme de calendrier placé à côté de la zone. Elle doit rester comprise dans votre exercice : sinon le logiciel refuse l'édition et affiche, sous la zone, le message « La date de calcul doit être comprise dans la période de l'exercice. »

| Champ                                         | Ce qu'il faut savoir                                                                                                                                                                                                                                                                                                                                                                                                                               |

Ces deux racines de comptes sont donc indispensables. Si elles ne sont pas renseignées, l'édition n'aboutit pas et le logiciel affiche un message d'erreur.

## Bouton \[Editer]

Il lance l'édition au format demandé. Il n'apparaît que si votre profil vous autorise à lancer cette édition.

## Bouton \[Mémoriser les paramètres]

Il sauvegarde tous les critères de l'édition en cours, colonnes retenues comprises, afin de pouvoir les réutiliser plus tard. Il ouvre une fenêtre intitulée « Mémoriser les paramètres de l'édition » qui vous demande d'indiquer le libellé du modèle d'édition : saisissez-le, puis validez avec le bouton d'enregistrement de la fenêtre. Le libellé est obligatoire ; s'il est déjà utilisé, le logiciel vous propose de mettre à jour le modèle existant plutôt que d'en créer un second.

## Bouton \[Charger les paramètres]

Il ouvre une fenêtre intitulée « Chargement des paramètres » présentant la liste des jeux de critères que vous avez mémorisés pour cette édition, sous leur libellé. Cliquez sur une ligne pour recharger ses critères dans l'écran, puis lancez votre édition. Chaque ligne porte aussi une commande de suppression, qui vous demande confirmation avant d'agir ; un jeu de paramètres utilisé par un point de contrôle d'un dossier de révision ou d'un modèle de dossier de révision ne peut pas être supprimé, et le logiciel vous le dit. Si vous n'avez encore rien mémorisé, la fenêtre affiche « Aucun élément à afficher. » ; refermez-la avec son bouton de fermeture ou le pictogramme « Croix ».
