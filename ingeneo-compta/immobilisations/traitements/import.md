# Import

{% hint style="info" %}
**Où le trouver :** Menu **Traitements › Import**
{% endhint %}

{% hint style="success" %}
**En bref** — Cet écran reprend en une fois, depuis la trame Excel du logiciel, les données d'immobilisations venant d'un autre logiciel : immobilisations, localisations, familles, subventions, emprunts et échéanciers personnalisés.

* Pour obtenir la trame : bouton \[Télécharger la trame d'import], puis remplissez ses onglets.
* Pour importer le fichier rempli : bouton \[Importer], puis consultez le rapport d'import.
{% endhint %}

Cette option permet de reprendre en une seule fois, à partir d'un fichier Excel, les données d'immobilisations provenant d'un autre logiciel.

<figure><img src="../../.gitbook/assets/15-cm852.jpg" alt="Écran Import"><figcaption><p>Écran « Import » de la nouvelle interface</p></figcaption></figure>

Comme ces logiciels emploient des formats très différents les uns des autres — contrairement à la comptabilité, où les écritures sont normées par le fichier des écritures comptables — le logiciel met à votre disposition une trame d'import : un fichier Excel dont vous n'avez plus qu'à remplir les onglets.

L'écran ne comporte ni rubrique, ni champ de saisie : il affiche le mode opératoire, puis vous laisse agir par ses boutons.

## Le mode opératoire affiché à l'écran

Les quatre lignes affichées résument la marche à suivre : téléchargez le fichier Excel contenant les trames d'import de chaque fichier ainsi que la notice explicative décrivant les caractéristiques de chaque champ ; remplissez ensuite les différents onglets avec les données à importer ; réalisez ensuite l'import ; le logiciel édite alors un rapport d'import.

Le pictogramme d'information placé au bout de la première ligne est le seul endroit de l'écran où figure la liste des données que vous pouvez importer. Il annonce « Cette option permet d'importer les fichiers suivants : » puis énumère :

* Immobilisations ;
* Localisations ;
* Familles ;
* Subventions ;
* Subventions étalement ;
* Emprunts ;
* Echéancier personnalisé.

Un onglet de la trame correspond à chacune de ces sept natures de données. La trame comporte en plus un onglet « Notes », qui décrit, pour chaque fichier, les caractéristiques dont doit disposer chaque champ.

## Bouton \[Télécharger la trame d'import]

Il télécharge sur votre poste la trame d'import du module, au format Excel.

## Bouton \[Importer]

Il lance l'import de votre fichier Excel rempli. Le logiciel édite ensuite un rapport d'import, comme l'annonce le mode opératoire affiché à l'écran.

## Cas particulier

Si votre logiciel d'origine produit un fichier d'export qui lui est propre, ne recopiez pas vos données dans cette trame : servez-vous de l'option « Imports spécifiques » du même menu, qui reprend directement les fichiers de certains éditeurs.
