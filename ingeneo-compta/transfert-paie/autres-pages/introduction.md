# Introduction

{% hint style="success" %}
**En bref** — Cette page présente le module « Transfert paie » : il sert à constituer chaque mois un fichier de variables de paie, à exporter vers votre logiciel de paie pour générer les bulletins.

* Pour constituer le fichier : importez les données de votre logiciel de gestion des temps, ou saisissez-les directement dans la rubrique « Saisies en cours ».
* Pour saisir directement : choisissez l'une des quatre formes de saisie, en grille, par page, par salarié ou par variable.
{% endhint %}

Cet outil permet la constitution d'un fichier de variables de paie mensuel.

La constitution du fichier des variables peut se faire soit **par l'import de données**, soit **par saisie directe** : la rubrique « Saisies en cours » offre pour cela quatre formes de saisie : en grille, par page, par salarié ou par variable.
