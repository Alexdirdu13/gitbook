# Actualités – Présentation

{% hint style="info" %}
**Où le trouver :** Panneau **Paramètres** › **Dashboard** › **Actualités**
{% endhint %}

{% hint style="success" %}
**En bref** — Cette page décrit le widget « Actualités » de l'onglet « Personnalisé » du panneau « Accès rapide », qui reprend les éléments des flux d'actualités paramétrés.

* Pour déclarer un flux : panneau « Paramètres », rubrique « Tableau de bord », onglet « Actualités », où vous indiquez l'adresse et le nombre d'éléments.
* Pour accéder à la configuration : cliquez sur le crayon « Configurer mes flux d'actualités », à côté du titre du widget.
{% endhint %}

La page d'accueil de Vision peut présenter un widget de type « Actualités », qui reprend les éléments des flux d'actualités paramétrés ; il se trouve dans l'onglet « Personnalisé » du panneau « Accès rapide », qui s'ouvre à droite du tableau de bord. Un flux se déclare dans « Paramètres », rubrique « Tableau de bord », onglet « Actualités », où vous indiquez son adresse et le nombre d'éléments à présenter.

<figure><img src="../../.gitbook/assets/19-cm365 (1).png" alt="Écran Actualités"><figcaption><p>Écran « Actualités » de la nouvelle interface</p></figcaption></figure>

Si vous avez accès au paramétrage des actualités, un crayon d'infobulle « Configurer mes flux d'actualités » figure à côté du titre du widget : il donne accès à la configuration des flux.

Le widget ne comporte ni filtre ni menu propre. Son en-tête porte, comme celui des autres widgets de l'onglet, une poignée « Déplacer » et un bouton « Replier ». Tant qu'aucun flux n'est enregistré, il affiche « Aucun élément à afficher ».

Ce widget ne présente pas les informations diffusées par votre cabinet : celles-ci font l'objet de fenêtres distinctes, décrites à l'option « Informations ».
